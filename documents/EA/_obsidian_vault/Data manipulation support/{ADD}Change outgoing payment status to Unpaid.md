# 🎯 {ADD}Change outgoing payment status to Unpaid

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Data manipulation support/HS3.0 and later/Outgoing payment manipulations

## 📝 Notes

{ADD PAYM-551 CBL-691 /}

This mBean changes a status of an outgoing payment from Order generating (G) or Paid (P) to status Unpaid (U). This can be requested in case payments are stuck in order generation or if there is a need for redisbursement (with a proper business justification).
