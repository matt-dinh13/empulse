# 🖥️ Versioned

> **Type**: GUIElement · **Stereotype**: «lcheckbox»
> **Package**: HomerSelect/BSL/Modules/Product Catalog (PRC)/Analytical Model/Sales Description/User Interface for Sales Description Management

## 📝 Notes

Checkbox distinguish if the sales description should be created as versioned (with version number of entity filled) or without version (will be available for all versions).
Once set to true, it can not be switched to false and all future sales description on entity will be versioned.
