# 🎯 {MOD}16.040 Process Account Event notifications

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Service Interpreter (SIR_NG)/Analytical Model/Use Case Model

## 📝 Notes

The use case present function for receiving, evaluation and processing of EventInfo notification generated by AM system.
Two event types are processed here:

	
- If the Account creation is confirmed by AM, the use case collects needed data continues with:
- adds all remaining Account Services via COS and add Sales Quote with the Service references to the Contract Supplement
- calls contractual documents creation.
	
- If the Account activation (i.e. MTCACC service is successfully switched on) is done in AM, it is continued with activation remaining services.


UC receives notifications from the am.headers.event.notification
AM sends EventInfo on: 

	
- account creation  ( event type = CREATE_ACCOUNT )
	
- account activation ( event type = ACTIVATE_ACCOUNT )
