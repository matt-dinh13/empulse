# 🎯 01.472 Push debt catalogue to external system

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Debt catalogue/Analytical Model/Access Rights

## 📝 Notes

This is a technical, non-visual use case which is used to push information about changed online debt for contracts into external collections system. Debt catalogues which are supposed to be pushed are taken from the special queue which holds information about contracts whose debt catalogue has changed recently and wasn't pushed to external system yet.
