# 🎯 01.483 Calculate debt on external request

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Debt catalogue/Analytical Model/Access Rights

## 📝 Notes

This use case is called by an external system in order to calculate debt on a particular contract to passed date (the date must be equal or greater then current date). 
There is going about a synchronous calling performed via OnlineDebtWS.calculateDebt().

Inputs:

	
- calculationDate
	
- contractNumber
	
- ignorePrepaymentsOnInactiveCETFER - default value false, if true and there is no active CET/FER request on contract and the sum of prepayments >= sum of debt, all prepayments are ignored and do not lower calculated debts


Outputs:

	
- debtOnAccruedInterest
	
- debtOnPrincipal


	
- debtOnFees - Debt on fees and penalties grouped by tariff item type codes
	
- prepayments
	
- {ADD CBL-11744 IS-1145}prepaidAmount (optional){/ADD}


Constraints:

	
- calculationDate >= current date

{/ADD}
