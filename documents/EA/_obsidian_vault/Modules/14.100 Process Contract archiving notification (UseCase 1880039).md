# 🎯 14.100 Process Contract archiving notification

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Document management (DMS)/Analytical Model/Document Instances/Access Rights

## 📝 Notes

The use case presents function for processing Contract notification for archiving
A ContractArchived notification message is received. DMS uses related Document uuids from the message (i.e. Contract Documents) to check existence of Document file content references
If a file reference is found on the Document, DMS creates DocumentArchived notification message for the Cabinet with the file reference(s) and sends it.
