# 🎯 08.050 Cancel Loan Service method (COS)

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Contract Services (COS_NG)/Analytical Model/Access Rights

## 📝 Notes

The use case presents a method for Contract Service (including Insurance) cancellation.
For the Deals (Insurances) where the premium is charged in BSL, there are cancelled possible authorized/confirmed transactions in AM (the outgoing payments are cancelled in VAS Deals).
Contract business event is generated only for Deal (insurance).

Call example:
https://api.cos.id00a1.cz.infra/rest/v1/contract-services/15465465/cancel
{
   "reasonCode": "BASE_CONTRACT_CANCELLED",
  "reasonNotice": "string"
}
