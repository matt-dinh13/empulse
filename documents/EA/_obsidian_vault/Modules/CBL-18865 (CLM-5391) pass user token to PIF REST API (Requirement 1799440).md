# 📋 CBL-18865 (CLM-5391) pass user token to PIF REST API

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Requirements/CBL-18865 (CLM-5391) pass user token to PIF REST API

## 📝 Notes

This requirement stipulates for passing user token in REST API request for getting PIF client information.
In case user token is passed, then masking on client data in response will be applied natively (in plain text), by PIF.
