# 🖥️ Search panel - All tickets

> **Type**: GUIElement · **Stereotype**: «panel»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Analytical Model/User Interface Model/Search for Tickets/Search panel - all tickets types

## 📝 Notes

Panel with search criteria for Search for tickets form - searching all ticket types, visible when 'TICKET_SEARCH' option is selected in Search type combo-box.

Rules for entering search criteria fields
1. Following fields can be entered independently:

	
- Status, Code, Reaction time exceeded, Resolving time exceeded, Category, Priority, Created from, Created to.

2. My processed ticket has to be entered together with a Status value

Localization code: TCK_AllTicketSearch
