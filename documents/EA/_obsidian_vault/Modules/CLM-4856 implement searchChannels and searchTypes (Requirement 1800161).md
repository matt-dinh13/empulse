# 📋 CLM-4856 implement searchChannels and searchTypes

> **Type**: Requirement
> **Package**: HomerSelect/BSL/Modules/Client center (CLC)/Requirements/CBL-16656/CLM-4856 implement searchChannels and searchTypes

## 📝 Notes

{ADD CLM-4856/}

Goal of this task is to develop methods for searching Channels and Types enumerations:

	
- searchChannels
	
- searchTypes


This will be used in BSL on tab Communication for filtering based on Channel and Type. User inserts name which will be, based on API search call, converted to code. Code is used then in searchCommunication.

Privileges for them are, respectively:

	
- PRI.COMMUNICATION_CHANNEL.SEARCH
	
- PRI.COMMUNICATION_TYPE.SEARCH
