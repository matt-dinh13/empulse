# 📋 CBL-19215 (CLM-5259) Add queue support - GUI

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Requirements/CBL-19215 (CLM-5259) Add queue support - GUI

## 📝 Notes

The goal of this ticket is to add new queue API features into GUI:

My tickets

Assign ticket to user automatically

	
- based on roles on passed queue
	
- based on roles from all queues
	
- overview of my assigned tickets


Ticket detail

Display ticket queues

	
- Add / Remove from queue on ticket detail
	
- Display Assigned user
	
- Assign / Unassign user from ticket on ticket detail
