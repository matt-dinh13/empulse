# 🎯 01.485 Publish debt full info job

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Debt catalogue/Analytical Model/Access Rights

## 📝 Notes

Use case prepares and publishes info about CEL debt for contracts in Debt Full Info Publishing Queue. Debt info is calculated by UC 01.486 Calculate debt full info and published via DebtFullInfoMessage notification. Use case is triggered by time and takes into account just contracts for which debt catalogue has changed.

Use case depends on

	
- UC 01.470 Update contract debt catalog which enqueues publishing requests into Debt Full Info Publishing Queue
