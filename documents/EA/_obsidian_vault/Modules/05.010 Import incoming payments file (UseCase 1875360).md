# 🎯 05.010 Import incoming payments file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Analytical Model/Import incoming payments/Use Case Model

## 📝 Notes

User executes this use case to import incoming payments contained in an external XML file. All payments in the file must have the same currency.
User selects one file for import from list of available files which are taken from importing directory - see Import incoming payments file user interface. 
System performs validations set of validation (Maximum file size, File duplicity) for the chosen file.
If validation passes, system runs import of data from the file to the system as asynchronous process - see 05.220 Process incoming payments file use case.

Frequency of usage:
  Several times a day
Actor:
  User role authorized to run the UC
