## 📝 Notes

List of active Service Eligibility Criteria Parameter Type assigned to selected ServiceEligibilityCriteria.ServiceEligibilityCriteriaType. 
I.e. if the definition of ServiceEligibilityCriteriaType was changed from the creation/last update then the inactive parameter types are removed and new ones are added. 
Displayed only if the list contains any row.
