# 📁 Create Commodity Data

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Modules/Commodity/Documentation/CMD

## 📝 Notes

Surrounding system can ask for creating a new commodity.

## Input

- commodity data values

## Output

- creation result
- commodity id (only if commodity is created)

## Detail

At first the system makes validations for correct commodity data on input and in case data is valid, system creates new commodity.
