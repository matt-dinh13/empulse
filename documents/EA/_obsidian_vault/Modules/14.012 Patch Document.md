# 🎯 14.012 Patch Document

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Document management (DMS_NG)/Analytical Model/Document Instances/Access Rights

## 📝 Notes

The use case presents a method for patching (update) of a document in the Document management module (DMS). 

This method support patching of more documents in one request.
Currently only update of attributes are supported (not files or other values).

Endpoint example:
PATCH  /documents/

+ JSON body
{
  [
  "documentUuid" : "111",
  "attributes": [
    {  "code": "ATTR1", 
        "value": "0"},
    {  "code": "ISS_DATE", 
        "value": "2020-04-30"}      
   ],
  "documentUuid" : "123",
  "attributes": [
    {  "code": "ATTR2", 
        "value": "1"},
    {  "code": "ISS_DATE", 
        "value": "2020-05-30"}      
  ]
]
}
