## 📝 Notes

Selection of source of communication records:

	
- All recent - load records from {MOD CLM-2831}selected{/MOD} systems,  use the COMM_HISTORY_LENGTH condition
	
- From BSL - load records from BSL only,  use entered Channel+Type value as filter condition
	
- From CCH - load records from CCH only, use entered Channel+Type value as filter condition


By default All recent is selected when screen is shown
