# 🎯 11.050 Get Insurance Program detail service v2

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Value Added Services (VAS)/Requirement model/CBL-12587 (CSI-1864) Custom data definition and validation

## 📝 Notes

The use case presents a service for getting an InsuranceProgram data based on provided externalId. The externalId is presented as insuranceProgramCode-versionNumber
If the versionNumber part is not provided, the service returns the currently active version of the Insurance Program.

GET example:
https://insr.vn00a1.cz.infra/rest/v2/insurance-programs/{externalId}?projections=CUSTOM_DATA
