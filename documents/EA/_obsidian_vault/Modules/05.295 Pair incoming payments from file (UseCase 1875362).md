# 🎯 05.295 Pair incoming payments from file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Analytical Model/Import incoming payments/Use Case Model

## 📝 Notes

System calls this asynchronous use case to perform automatic pairing of incoming payments which are related to the confirmed file. 
Within this activity, following actions are performed:

	
- System tries to find contracts by provided data of payment and checks if the pairing can be done. Having a check failed, the contract is excluded from pairing.
	
- Next, pairing payments to found contracts is performed by 05.182 Pair payment with contract use case.
	
- Contracts paired with payments are forwarded to 05.184 Reflect change of balance use case to perform actions invoked by balance change (e.g. early repayment) and final pairing payments to the contract installments.


If REL contracts are determined for payment pairing, data is handed over to CaBus and finalization of payment processing is done by 05.297 Process results of incoming payment pairing use case.
The process is finished by 05.298 Check incoming payment file for finish use case as soon as all the payments in the file are processed
