# 📋 CBL-21173 (CLM-5888) New GUI to be created to manage Hosel allocation tool queue in realtime

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Requirements/CBL-21173 (CLM-5888) New GUI to be created to manage Hosel allocation tool queue in realtime

## 📝 Notes

Business needs faster than IDM-driven assignments to queues, so a real-time solution to have supervisor assign agents to (multiple) queues is required.

Additional requirements

	
- Permission for ticket assignment via REST API to be given to all users but visibility of self-assign button will depend  on if user is assigned to given queue. If not, the button will be disabled.


	
- Only supervisor will be able to see which users belong to which queue and to manage them, agents will not be able to see user assignments.
