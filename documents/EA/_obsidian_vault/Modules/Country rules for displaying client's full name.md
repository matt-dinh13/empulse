# 📋 Country rules for displaying client's full name

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Analytical Model/Management of incoming payments/Business Rules

## 📝 Notes

The way the client's full name is displayed depends on country.
 

	
- Default: First name + Middle Name + Last name, e.g. "First Middle Last"
	
- KZ: Last name + First name + Middle name
	
- PH: First name + Middle name + Last name + Honour
	
- VN: Last name + Middle name + First name
