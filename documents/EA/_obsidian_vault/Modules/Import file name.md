# 🖥️ Import file name

> **Type**: GUIElement · **Stereotype**: «text»

## 📝 Notes

Name of import file (INCOMING_PAYMENT.FILE.NAME)
File name can be entered in short form
XXXXXXX_YYYY-MM-DD_N
Or in full length
IncomingPayments_XXXXXXX_YYYY-MM-DD_N.xml
Asterisk can be used with combination with at least one character. Asterisk represents any string of text from empty string up to entire paragraph or more.
