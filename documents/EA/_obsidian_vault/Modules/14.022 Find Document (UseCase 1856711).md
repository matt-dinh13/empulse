# 🎯 14.022 Find Document

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Document management (DMS_NG)/Analytical Model/Document Instances/Access Rights

## 📝 Notes

The use case presents a method for getting the document details for specific list of UUID, document type, attribute or file in the Document management module (DMS). List of found document is returned (empty array is returned if no document is found).

Endpoint example:
GET /documents/

query params:
- attributeCode
- attributeValue
- typeCode
- documentUuids (new list of documentUuid)
- documentFlag
- fileUuids (changed to list of fileUuid)
- projections
- limit
- offset
