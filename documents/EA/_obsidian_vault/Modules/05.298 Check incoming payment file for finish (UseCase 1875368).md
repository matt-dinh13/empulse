# 🎯 05.298 Check incoming payment file for finish

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Analytical Model/Import incoming payments/Use Case Model

## 📝 Notes

The use case describes automatic checking of unprocessed incoming payment files whether can be finished. As soon as all the payment in the checked file are processed, the file is marked as processed and the user who starts pairing process is noticed about a result of payments pairing by receiving a message to the system inbox (see Incoming payment file pairing message structure ). 
The use case is run automatically in planned time (see Check Payment File For Finish job proposal)
