# 📋 Filename extension format

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Analytical Model/COMMON for Ticketing/Validation rule definitions

## 📝 Notes

{ADD CLM-1944 /}
This validation checks the file name extension on correct format by following rule:

	
- filename extension has to start with dot (ASCII 47)
	
- extension contains 1 up to 4 printable characters (Aa-Zz; 0-9); upper case/lower case aren't taken into account


Examples: .PDF, .png, .JPEG
