# 🎯 10.010 Search for tickets

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Analytical Model/User Interface Model/My overview

## 📝 Notes

The use case describes user interface logic of searching tickets

Typical usage of ticket searching:

	
- Back office user roles use "all ticket" search, to manage their daily tasks, depending on department of which they are member
	
- Front office user roles (e.g. POS employees) use the ticket search to search Contract mistakes which are recorded to contract documents. Possible access to the search function:
- Rotating POS employee  can display contract mistake tickets of contracts which he created.
- POS employee who is not rotating can display contract mistake tickets of contracts created on his active POS (the salesroom which user has set as active in user management).
