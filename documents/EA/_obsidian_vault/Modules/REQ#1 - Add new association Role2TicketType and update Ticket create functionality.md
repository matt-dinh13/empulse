# 📋 REQ#1 - Add new association Role2TicketType and update Ticket create functionality

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Requirements/CBL-5471 (CLM-1959) TCK - Define restricted access for Ticket Type

## 📝 Notes

Role2TicketType defines which role can create which ticket type.
If no association (record) is defined for the role, then the role can create any ticket type.

It is used in 10.023 Get Ticket Categories service  + 10.024 Get Ticket Types service
