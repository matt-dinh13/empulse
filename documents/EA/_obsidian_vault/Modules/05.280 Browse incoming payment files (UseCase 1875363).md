# 🎯 05.280 Browse incoming payment files

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Analytical Model/Import incoming payments/Use Case Model

## 📝 Notes

Authorized user is allowed to browse list of incoming payment files which have been successfully imported into the system.
Files can be searched by parameters described in the Browse incoming payment files screen.
If a file is found, user can perform following action on the screen:

	
- For still unprocessed files, user can run automatic pairing of payments from a file to contracts - see 05.290 Confirm incoming payment file use case. 
	
- For still unprocessed files, user can choose a file and remove it from the list - see 05.292 Remove incoming payment file


Frequency of usage:
  Several times a day
Actor:
  User role authorized to run the UC
