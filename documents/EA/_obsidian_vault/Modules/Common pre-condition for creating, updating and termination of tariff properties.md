# 📋 Common pre-condition for creating, updating and termination of tariff properties 

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Product Catalog (PRC)/Analytical Model/Tariff/User Interface for Tariff Management/Tariff Root/Business Rules

## 📝 Notes

- Tariff version must be selected in status Inactive.
	
- Mode (CREATE, UPDATE) must be defined for setting (creating, updating) of property.
	
- Tariff property must be selected for updating/cancellation of an existing property.
