# 🎯 05.012 Automatic import incoming payments via WS

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Interface provided/Provided WS/PaymentsWS (INCPAY)

## 📝 Notes

System executes this use case to import incoming payments contained in an external XML file. All payments in the file must have the same currency.
External system calls web service for import incoming payments file.

System performs validations set of validation (Maximum file size, File duplicity) for the chosen file.
If validation passes, system runs import of data from the file to the system as asynchronous process - see 05.220 Process incoming payments file use case.

Frequency of usage:
  Several times a day
Actor:
  An external system (out of Homer Select Suite) authorized to run the UC
