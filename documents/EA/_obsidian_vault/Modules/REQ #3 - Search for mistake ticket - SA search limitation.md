> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Requirements/CBL-8891 (CLM-2860) Sales Agents contract search limitation

## 📝 Notes

Goal of this requirement is to implement a Ticket search like "Mistake tickets - person limit" where the person limit is defined as search for tickets related to contracts (i.e. related subject) created by logged user which are opened less than or equal 30 days. The mentioned requirement will be implemented in the new TCK module only.
