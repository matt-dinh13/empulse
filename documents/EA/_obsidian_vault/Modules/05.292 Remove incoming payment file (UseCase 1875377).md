# 🎯 05.292 Remove incoming payment file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Analytical Model/Import incoming payments/Use Case Model

## 📝 Notes

The use case describes removing an imported payment file.
First, user has to find an unprocessed file to run this action - see 05.280 Browse incoming payment files use case.
After the action is run, the system removes intended file from the list of incoming files as well as all payments which are contained there. User can remove only unprocessed file from the list.

Frequency of usage:
  Several times a day
Actor:
  User role authorized to run the UC
