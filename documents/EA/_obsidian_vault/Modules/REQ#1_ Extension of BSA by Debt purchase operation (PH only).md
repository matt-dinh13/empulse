# 📋 REQ#1: Extension of BSA by Debt purchase operation  (PH only)

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Contract bulk operations (BSA)/Requirement model/CBL-30268 (CSI-4570) Debt Purchase support

## 📝 Notes

Changes in the Logical model:
- new operation type DEBT_PURCHASE
- update of Contract Result table - field ContractCode set as NULL able (will not be filled for new Debt Purchase items)
- new Debt Purchase Operation table
- new Debt Purchase Result table

Changes in the UI:
- new form for creation of Debt purchase

Changes in the UC and Access rights:
- new 08.761 Create Debt purchase bulk operation
- new 08.763 Execute Debt purchase bulk operation
- update of common UC 08.711 Execute bulk operation to support Debt purchase

Changes in integration:
Provided:
- expose new API for creation of DEBT_PURCHASE bulk operation including items (same API which is used between front end and back end)
- new Rabbit MQ notification generated by BSA for each Debt Purchase item (received by Zeebe to start process)
- extend BSA Rabbit notification by new operation and extended information

Consumed:
- new Rabbit MQ notification consumed by BSA to receive status of Debt Purchase item (generated by Zeebe)
- processed by new UC {ADD}Process DebtPurchaseNotification

Each Debt Purchase item will use unique UUID (correlationID) which will be used in both Rabbit MQ.
