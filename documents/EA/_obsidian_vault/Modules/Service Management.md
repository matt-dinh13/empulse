# 📁 Service Management

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Modules/Product Catalog (PRC)/Documentation/PCG

## 📝 Notes

Service management is one of main business entities of Product catalog module (PCG). It consists of these key entities:

- Service Type - groups together services which provide the same service/option/feature only with different settings, conditions or price.
- Service - defines parameters for specific service type

A combination of service type and service enables  to store information about different kinds of service data.

## Data structure

- Service Type
- Service Type Flag
- Service
- Service Eligibility Container
- Service Exclusivity Rule
