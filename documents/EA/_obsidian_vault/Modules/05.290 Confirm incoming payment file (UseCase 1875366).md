# 🎯 05.290 Confirm incoming payment file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Incoming Payments/Analytical Model/Import incoming payments/Use Case Model

## 📝 Notes

The use case describes automatic pairing of payments located in an imported payment file.
First, user has to find a unprocessed file to run this action - see 05.280 Browse incoming payment files use case
After the action is run, system checks if the file has not been processed yet.
Next, there is checked if deposit date is entered for the file here. If no, system prompts the user to enter date before the process starts. 
Finally, it is started automatic process described in the 05.295 Pair incoming payments from file use case.

Frequency of usage:
  Several times a day
Actor:
  User role authorized to run the UC
