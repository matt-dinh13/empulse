# 📋 REQ#2 - Storage Ticket Priority for Mistake tickets

## 📝 Notes

This proposal describes saving Ticket Priority on the Ticket object. The current solution is not suitable for Mistake tickets because the Priority of a mistake is depended on Ticket Type and Document Type and it is defined in the Mistake Rule object.
