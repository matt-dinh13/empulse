# 🎯 {ADD}Process DMS DocumentNotification

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Contract Management (COMA)/Requirements/CBL-30572 (CLM-7349) Process DMS document notification

## 📝 Notes

{ADD CLM-7349 /}
System receives kafka DocumentNotification event from DMS system with event type DocumentExpired (it is generated by DMS only for file expired event from CAB). Other event types are ignored by COMA.

System takes document TypeCode and UUID from notification.
System finds document flags related to TypeCode (by calling DMS get document type) and tries to find UUID value in following relations:

	
- if flags contains CONTRACT value then Contract document relation, else
	
- if flags contains PERSON value then Client document relation, else
	
- if flags contains DDM value then DDM document relation



If some relation is found, then the relation is archived.

Note: 
Searching by document UUID is not common, so check of existency or creation of correct index and some performance testing of the used query is needed.
