# 🎯 11.124 Validate data eligibility for insurance

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Value Added Services (VAS)/Analytical Model/Insurance Program/Insurance Program functionalities/Access Rights

## 📝 Notes

This use case describes validations of the client and commodity eligibility criteria for insurance defined by Insurance Programs and their Version Number.  If the versionNumber is not provided, the service uses Eligibility Definitions of the currently active version of the Insurance Program.
The check is done with data provided on the input of the service together with a list of Insurance Programs providing eligibility criteria.
If the ignoreMissingValues = TRUE, the function skips validation of missing attributes even if the values are required by the insurance program eligibility rules.
The service returns final result of insurance program eligibility for all provided data, next separately for client and commodities and detail list of failed eligibility checks for client and commodities.
