# 🎯 11.002 Find deal (VAS)

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Value Added Services (VAS)/Analytical Model/VAS Deal/Access Rights

## 📝 Notes

The use case presents a method to find a deals according to input parameters in the Value added module (VAS). 
List of found deals is returned (empty array is returned if no deal is found).

Endpoint example:
GET  /deals/params

query params:
- uuids
- codes
- customerIds
- relatedContractCodes
- relatedCommodityIds
- statuses
- types
- limit
- offset
