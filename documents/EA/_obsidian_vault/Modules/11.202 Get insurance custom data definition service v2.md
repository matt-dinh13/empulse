# 🎯 11.202 Get insurance custom data definition service v2

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Value Added Services (VAS)/Analytical Model/Insurance Program/Insurance Program functionalities/Access Rights

## 📝 Notes

This use case presents a method of insurance service for getting custom data definitions based on provided externalId. The externalId is presented as insuranceProgramCode-versionNumber. If the versionNumber part is not provided, the service returns  custom data definitions of the currently active version of the Insurance Program.

GET <INSR_ADDRESS>/rest/v1.0/insurance-programs/{externalId}/custom-data
