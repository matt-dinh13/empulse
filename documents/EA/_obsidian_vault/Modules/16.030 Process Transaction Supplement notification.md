# 🎯 16.030 Process Transaction Supplement notification

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Service Interpreter (SIR)/Analytical Model/Access Rights

## 📝 Notes

The use case presents a function for processing ContractSupplement notification messages of the TransactionSupplementAcceptedEvent and  TransactionSupplementCancelledEvent types.
The function checks the VAS deals (Insurance Contracts) existence on the loan transaction. If a VAS Deal is found, the function gets related SalesQuote financial parameters and try to activate the VAS deal via API.
