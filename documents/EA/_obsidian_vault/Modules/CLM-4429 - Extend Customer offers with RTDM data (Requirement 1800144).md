# 📋 CLM-4429 - Extend Customer offers with RTDM data

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Client center (CLC)/Requirements/CBL-15196/CLM-4429  - Extend Customer offers with RTDM data

## 📝 Notes

On load of tab Customer offers system calls RTDM for each client's offer (1 request per offer). From each response system gets:

	
- CRM business hint
	
- CRM business hint description
	
- Guideline URL

System displays hint and description as fields and url as a link.
