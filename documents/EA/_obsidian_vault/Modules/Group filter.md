# 🖥️ Group filter

> **Type**: GUIElement · **Stereotype**: «combobox»
> **Package**: HomerSelect/BSL/Modules/Product Catalog (PRC)/Analytical Model/Tariff/User Interface for Tariff Management/Tariff Root/User Interface

## 📝 Notes

Listed: Tariff.TariffItem.Group.Name (unique Group.Names from the full list of Tariff Items like MS Excel filtering)
After any name is selected then the list of Tariff Items is filtered according to selected group name.
After the selection is canceled then the full list of Tariff Items is displayed (default status).

Localization code: TAR_GroupFilter
