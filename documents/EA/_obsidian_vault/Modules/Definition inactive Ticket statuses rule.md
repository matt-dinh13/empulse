# 📋 Definition inactive Ticket statuses rule

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Modules/Ticketing (TCK)/Analytical Model/Use Case Model

## 📝 Notes

A list of inactive Tickets can be defined by user according the Ticket status.
The values are taken from SystemConfig.InaciveStatuses
Default setting of inactive statuses for all country:

	
- CLOSED, CANCELLED
