# 🎯 11.040 Activate Deal (VAS)

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Value Added Services (VAS)/Analytical Model/VAS Deal/Access Rights

## 📝 Notes

This use case presents a method for Deal activation. It means, it is evaluated Deal, Client, Commodity eligibilities, determined and created Deal period of activity, and set Operation status (SWITCHED_ON) in case the Deal is associated with REL contract. 
REL Deal (insurance) types are supported only.

Method v1 example:
https://api.vas.<environment>/rest/v1/deals/{uuid}/activate
{
  "billingDay": 5,
  "activationDate": "2024-02-14",
  "reasonCode": "ACTIVATED_MANUALLY",
  "reasonNotice": "string"
}
