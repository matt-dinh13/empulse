# 🎯 08.580 Activate Insurance Program version manually

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Modules/Value Added Services (VAS)/Analytical Model/Insurance Program/Insurance Program management/Access Rights

## 📝 Notes

This use case is intended for activation of inactive insurance program version.
If insurance program validation is OK then user can activate insurance program version immediately or on required date and time.
After activation the insurance program can be assigned to insurance service and used for preparation of product offers.
