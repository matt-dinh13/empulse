# 📄 General document validation

> **Type**: Action · **Stereotype**: «RuleTask»
> **Package**: N/A

## 📝 Notes

General business rules for Filipino identification documents.

	
- For documents with flag Document.isPrimary = YES no duplicity in document Id number is allowed.


	
- all numbers involved in document have to be written down in European digits
	
- all text chars used in document have to be written with Latin alphabet
