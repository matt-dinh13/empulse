# 📋 Manage list of Service Categories and Service Types

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: N/A

## 📝 Notes

- If Service category is selected then the list of service types in the field Service type is filtered by service category. If already selected service category does not correspond with already selected service type, the field Service type is cleared.
	
- If Service category is cleared then the filtering of service types in the field Service type is stopped.
