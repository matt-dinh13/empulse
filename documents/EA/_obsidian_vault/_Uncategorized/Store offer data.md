# 📋 Store offer data

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: N/A

## 📝 Notes

System creates offer data from output of product calculator.
This rule describes how offer generated by product calculator is stored in the system.
 

	
- System creates Offer Financial Parameters
	
- System saves each commodity according to the rule Create application commodity.
	
- System creates Offer Service (or its defined subclass) instances for all services and insurance services adjusted in the offer 
- Offer Insurance Service instance for insurance services (that means services whose service type is from Insurance category). Attributes are set as follows:
-- Insurance Contract Code is not set
-- Insurance Program Code is set to Insurance Service.Program Code
-- Insurance Program Version is set to currently active version of given Insurance Program.
-- Sum insured is calculated as a sum of values for all tariff items with usage "Sum Insured" (found by Find tariff items by usage with tariff and usage as params from the service's tariff) according to rule Calculate tariff item amount with params tariff item, offer financial parameters, service, commodity price (if the service has a reference to specific commodity), estimated first period start and end as parameters.
-- Estimated First Period Start set to value calculated in product calculator
-- Estimated First Period End set to value calculated in product calculator
System creates Offer Financial Parameter Item (or its defined subclasses) instances.
- OFP Service Tariff Item instance for an item linked to the service with link to Offer Service set to the respective service.
	
- For all Offer Insurance Service instances created system creates Offer Insurance Custom Data instances for all Insurance Custom Data Def defined for the insurance program (identified by Offer Insurance Service.Insurance Program Code and Insurance Program Version) with empty values.
