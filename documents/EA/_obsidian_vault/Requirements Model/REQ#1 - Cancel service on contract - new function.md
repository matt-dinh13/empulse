# 📋 REQ#1 - Cancel service on contract - new function

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-6070 (CLM-2053) New service type for offering additional product

## 📝 Notes

Goal of this requirement is to support a new service type (to sell handset bundle offer together with mobile phones - HBO) so that authorized back office user is able to cancel this one via Contract detail-Service tab.
In this case, it is needed to recalculate the contract financial parameters and regenerate the installment schedule (similar to Insurance cancellation).
