# 📋 REQ #1 - Implement configurable contract search system criteria

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-10618 (CLM-3352) Limitation of search function on BSL for back office

## 📝 Notes

Contract search filters selecting results contracts based on:

	
- user criteria - provided by user via gui
	
- system criteria - general limitation applied independently from user inputs


In current filters system criteria are fixed, therefore they can not flexibly reflect country requirements.

Goal of this task is to make system criteria configurable.
