# 🖥️ Add available services

> **Type**: GUIElement · **Stereotype**: «button»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-6572 (CLM-2126) Disable gift payment and grace period when PER is executed

## 📝 Notes

Button is active only for REL contracts: Contract.Contract Type = REL

By selecting 'Add available services' button user can add other available REL services which are not currently related to the REL contract, e.g. the new ones which were added on the product related to current contract during the contract lifecycle.

Localization code: SER_AddAvailableServices_button
