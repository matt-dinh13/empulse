# 🎯 01.801 Import sold contracts file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-4472 (CLM-1687) PH Contract Debt Sale

## 📝 Notes

User executes this use case to import file with list of sold contracts. Sold contracts are presented by records an external file of standardized XML format. For the file structure description see SoldContractsFile. 
User selects one file for import from a directory - see Import sold contracts file screen.
System performs validations set of validation (Maximum file size...) for the chosen file.
If validation passes, system runs import of data from the file to the system as asynchronous process - see 01.802 Process sold contracts file use case.

Frequency of usage:
Several times a week
Actor:
User role authorized to run the UC
