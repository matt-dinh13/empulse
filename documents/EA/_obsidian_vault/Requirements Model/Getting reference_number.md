# 📋 Getting reference_number

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CSI/CBL-19452 [SCL] (CSI-2284) ABDA Insurance Order Integration/ABDA request - data mapping

## 📝 Notes

The reference number is generated by BLAZE (used template format:  HCID[DDMMYYYY][CN]) and used within the SCL underwriting process as unique identifier of the request when RCM calls the ABDA API "inquiry" method.
We need to store the reference number into a document for using this for calling ABDA API "order" method within After contract activation post processing.
The reference_number storege will be ensured UW Zeebe process (LAP) as follow:

	
- get reference_number from fullpath of ..Result.registerSettings[].referenceNumber (e.g. HCID020220234300199955)
	
- call DMS POST documents method for document creation
Parameters:
- typeCode = "VEHICLE_INSURANCE",
- creationMoment = "CA",
- attributes":
   -- code = "PARTNER_REFERENCE_NUMBER",    value = reference_number
