# 📝 Tariff Item Usage

> **Type**: Enumeration
> **Package**: HomerSelect/BSL/Requirements Model/Finished/PCG/PCG-196 Interest rate of the overdue principal debt (CBL-40)

## 📝 Notes

Defines category of usage for fee/penalty type. This code is used to search of fee related to an event (e.g. Early repayment) when is to be charged. 
Important notice: This enumeration is related to the Recalculation Reason, it means codes of events have to be the same in both entities.
