# 📋 Requirement1 - Update of file name parsing for document automatic loading for IN

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-2646 (CLM-1158) Naming convention of auto upload of client documents

## 📝 Notes

Extend FileName parsing to use numeric suffix in more flexible way.
Currently possible format:  CN_XX.ext where XX define document type, e.g CN_01.pdf, CN_02.pdf.
Required possible format: CN_X.ext or CN_XXX.ext, eg. CN_1.pdf or CN_001.pdf should be also used as type 01.
