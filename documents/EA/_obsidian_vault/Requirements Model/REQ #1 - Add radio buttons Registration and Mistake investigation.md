# 📋 REQ #1 - Add radio buttons Registration and Mistake investigation

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-8291 (CLM-3246) VN - Paperless - contract Registration Queue optimization - Enhancements V3

## 📝 Notes

Goal of this task is add radio buttons Registration and Mistake investigation to select which registration task will be assigned to user.

Radio buttons are available on following screens:

	
- Registration queue
	
- Register contract


Last selected radio button is saved and automatically selected for next screen visit.

This functionality is controlled by global database parameter enhanceRegistrationQueueV3.
