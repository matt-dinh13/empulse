# 📋 REQ#1 New access right for Client Documents

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-6279 (CLM-2061) New access right for Client Documents

## 📝 Notes

Goal of this project is to implement new access rights for:

	
- Preview client document
	
- Download client document


Preview client document is currently controlled by basic access right, from where it will be separated to specific access right.

Download client document is controlled together with download contract document by specific access right. Next to this right will be implemented additional rights to control client and contract documents download separately.
