# 📋 CSI-2721 Preview financial parameters of the chosen Insurance

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CSI/CBL-20284 (CSI-2701) Add Insurance To CEL Contracts

## 📝 Notes

Goal of this requirement is a new function to preview financial parameters for chosen insurance to be added on a Contract available via API and BSL UI.

	
- get Service setting of the chosen insurance
	
- get used tariff item of the chosen insurance
	
- get the current financial parameters of the loan
	
- calculate a premium amount - could be only fix (monthly) fee allowed for simplification
	
- calculate future financial parameters of the loan when the premium is involved from defined installment
	
- create screen to show the Insurance parameters
	
- expose the Insurance parameters via a REST method
