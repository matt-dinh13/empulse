# 📋 CSI-2222 Change LoanService status on defined Account Closure notifications

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CSI/CBL-18500 (CSI-2052) Change flag SERVICE_SWITCH_ALLOWED for ACCSTMT service type

## 📝 Notes

Following will be developed within this story:

	
- Create a new functionality for receiving the Account Closure notifications and based on Service setting process the ContractService statuses, possibly operational statuses
	
- Integrate the new functionality to the RMQ exchange of am.topic.account.closure


The account.closure message structure definition and examples:

	
- https://jira.homecredit.net/jira/browse/ACM-3580


Message types routing:

	
- Payoff notification: Routing key = Payoff.v3
	
- Write-off notification: Routing key = Writeoff.v3
	
- Account closed: Routing key = TBD


Next part of the task is removing consuming the "Payoff" notification generated by Contract. Currently, processing this notification is ensured by UC Process ContractPaidOffSE [CSI] which is intended only for the insurance deactivation only.
Rule for usage new and the old approach for account/contract events processing:

	
- if the new UC 08.295 Process Account Closure notifications is switched-on, Process ContractPaidOffSE [CSI] must be switched-off
