# 📋 CBL-53 CKYC support

> **Type**: Requirement · **Stereotype**: «Epic»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CLM-90 (CBL-53) CKYC support

## 📝 Notes

Business Objective:
Documents scanned by third party will be automatically uploaded from defined folder in SFTP to BSL by daily batch job.
According to naming convention of scanned files batch job will be able to match them to the documents that have been already created in BSL.
Afterwards the job will transfer successfully matched files to defined folder with successfully uploaded documents and the ones, that were not matched, to another defined folder.
Finally the report about file import will be generated and stored at SFTP as well.
