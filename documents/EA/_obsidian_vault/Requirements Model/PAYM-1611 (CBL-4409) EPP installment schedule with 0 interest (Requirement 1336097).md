# 📋 PAYM-1611 (CBL-4409) EPP installment schedule with 0 interest

> **Type**: Requirement · **Stereotype**: «Epic»
> **Package**: HomerSelect/BSL/Requirements Model/In process/ISPAY/PAYM-1611 (CBL-4409) EPP installment schedule with 0 interest

## 📝 Notes

Installment schedule generated via a rarely used EPP (Equal Payment Principal) algorithm is not designed to work with 0 % interest. KZ would like to use this algorithm also for 0 % interest, typically due to grace period application as requested in I-210863.
