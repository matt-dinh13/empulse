# 📋 REQ #1 - Allow pdating bank account for consolidated contracts in status signed

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-11279 (CLM-3521) Updating External Bank information after contract signing in Consolidation tab

## 📝 Notes

Goal of this task is to allow updating bank account for consolidated contracts in status signed. But only if disbursement payment was not yet paid.

This allow back office to modify bank account information after contract approving if there is a need.

This feature is controlled by the global database parameter allowAccountUpdateForSignedConsolidationContrat.
