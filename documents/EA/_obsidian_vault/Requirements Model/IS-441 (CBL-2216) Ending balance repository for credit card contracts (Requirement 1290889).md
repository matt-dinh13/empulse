# 📋 IS-441 (CBL-2216) Ending balance repository for credit card contracts

> **Type**: Requirement · **Stereotype**: «Epic»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/IS/IS-441 (CBL-2216) Ending balance repository for credit card contracts

## 📝 Notes

At present, in order to reduce the number of complaints from customers about the total debt of each billing cycle (referred as "Ending balance”) appeared in the Collection SMS, it’s required to create a new “Ending balance” repository which will be used in our Collection SMS. This Ending balance repository should reflect the total debt that will be due during the current billing cycle.
