# 📋 REQ#2 - new REST API for LRES create request, get offers and confirm offer

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-9759 (CLM-3059) Create API for Loan restructuring

## 📝 Notes

CreateContractLRESRequest service (POST) creates a new LSR and send request to LAP for offers.

GetContractLRESRequestOffer (GET) provides list of LSR and available offers.

ConfirmContractLRESRequestOffer (PUT) confirms selected LSR and Offer.
