# 🎯 01.802 Process sold contracts file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-4472 (CLM-1687) PH Contract Debt Sale

## 📝 Notes

System calls this asynchronous use case to upload and processing sold contract from a file. 
System uploads the file from a directory chosen by user and performs formal and business validations on that.
Having a validation failed, system rejects the entire file and user who runs the action is noticed about the problem by receiving a message to the system inbox. Invalid records are noted to an error file and reported to user. The system calls 01.901 Perform contract sale through which is the contract sale process finished.
