# 📋 Enhance some Contract Management’s web service by new method by which it would be possible to edit document attributes

> **Type**: Requirement · **Stereotype**: «Epic»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CLM-776 (CBL-1324) Paperlerss REQ14 - Edit documents

## 📝 Notes

- Business story
	
- HoSel impact description



As per business process in paperless application after signature of contract sales agent has to enter Invoice number and Invoice date. Current setup in BSL is that after contract signature the Invoice document is created but there is no option to edit its attributes.

	
- 
	
- Solution proposal



Our proposal is to enhance some Contract Management’s web service by new method by which it would be possible to edit document attributes.
