# 🎯 01.184 Process ContractSignTransactionsSE event

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CLM-819 (CBL-860) Unification reimbursement from credit cards

## 📝 Notes

This purely technical use case describes processing of the ContractSignTransactionsSE system event. It solves a technical issue in communication between BSL and AM at the initial POS transaction confirmation.
The event is triggered in use case 01.187 Sign contract where all initial transactions are authorized (instead some of them are directly confirmed) and, subsequently, the corresponding transactions are confirmed in this use case.
