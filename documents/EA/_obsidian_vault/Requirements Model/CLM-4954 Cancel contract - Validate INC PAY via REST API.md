## 📝 Notes

Goal of this task is to check for incoming payments based on REST API call to INP module instead of direct database call.

The following uses case are affected by this change:

	
- 01.330 Cancel signed contract manually
	
- 01.331 Cancel signed contract with invalid commodity
	
- 01.332 Cancel signed contract service
	
- 01.333 Cancel active contract service
	
- 01.590 Cancel active contract manually
	
- 01.592 Cancel paid-off contract manually
