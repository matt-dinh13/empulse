## 📝 Notes

GET ContractCHDDRRequest preview returns availability, notification message, list of possible due days and calculated results of CHDDR simulations if new due date is provided and correct.

PUT ContractCHDDRRequest  creates CHDDR requests for provided DueDate and InstallmentNumber and returns LSR Id.
