# 🎯 13.300 Process AM EventInfo notification

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CSI/CBL-20608 (CLM-5431) Expiration of Virtual Limit Contracts

## 📝 Notes

This use case describes processing the EventInfo notification (message) received from AM (via AMQP). This notification provides some information about:

	
- a statuses of the transaction which are needed for Transaction Contract Supplement
	
- account expiration

The respective notifications will be identified based on loanCode, AccountNumber (the same as Contract.Contract Code) and event type

The notification serves as trigger of following events in the system:

	
- POS/Cash transaction cancellation - it reacts to AUTHORIZATION eventType with "cancelled"= true and triggers transaction cancellation
	
- Cash transaction is paid - it reacts to ADVANCED_ALOP/NO_CARD_CASH_REPEAT eventType and triggers transaction is paid to client
	
- account expiration - it reacts to ACCOUNT_EXPIRATION event type
