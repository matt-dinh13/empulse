# 📋 REQ#1 - Contract search - new access rights for predefined filters

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-4153 (CLM-1594) Contract search - new access rights for predefined filters

## 📝 Notes

The goal is to add new access rights for following predefined filters in Contract search screen:
Code=UC01_300_InProcess
Code=UC01_300_Reimbursed
Code=UC01_300_Nonreimbursed
Code=UC01_300_ForRegistration

To have clear names for all predefined filters we also update names for following access rights:
Code=UC01_300_A4_AC to Code=UC01_300_Canceled
Code=UC01_300_A5_AC to Code=UC01_300_Drafts
Code=UC01_300_A6_AC to Code=UC01_300_CreatedByMe
