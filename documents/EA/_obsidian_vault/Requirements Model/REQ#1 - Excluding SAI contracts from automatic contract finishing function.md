# 📋 REQ#1 - Excluding SAI contracts from automatic contract finishing function

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-6146 (CLM-2017) Change Logic of Payment Reversal for SAI Contract

## 📝 Notes

Goal of this requirement is to exclude SAI contract types from automatic contract finishing function.
A reason for that:  debt on the SAI contracts are not recorded in the Debt catalogue so the SAI contract finishing cannot be correctly evaluated in case of reactivation and follow-up finishing after repayment.
