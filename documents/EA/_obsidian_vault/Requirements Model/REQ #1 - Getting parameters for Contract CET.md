# 📋 REQ #1 - Getting parameters for Contract CET

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-3825 (CLM-1460) Create CET/FER request in Mobile banking system

## 📝 Notes

This part of the requirement describes how to get some parameters and information needed to the CET request creation on an external request.
It is supposed, the user of an external application has a contract identified, gets available services for the contract and chooses a CET service available to the request creation. (GET ContractServices REST service can be used for the mentioned).
