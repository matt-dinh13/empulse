> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-8033 (CLM-2485) Get presented interest rate by web service

## 📝 Notes

Based on the RBI audit we need to provide to customer effective interest rate recalculated for simple interest (APR), calculation of new presented interest rate is implemented under CBL-7690.

All presented interest rates should be accessible through Web service (REST is preferred) with other contract financial parameters.

Goal of this task is to modify the current REST Contracts service so that all PIRs on loan account are returned.
