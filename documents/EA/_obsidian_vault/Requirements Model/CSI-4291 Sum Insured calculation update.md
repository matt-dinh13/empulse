# 📋 CSI-4291 Sum Insured calculation update

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/In process/CSI/CBL-31091 (CSI-4288) - Adding Insurances and Services to Existing Contract in POS Loan and Cash Loan - Sum Insured calculation

## 📝 Notes

Goal of the requirement is enabling calculation of Sum Insured (Tariff Item) based on Product catalogue Tariff setting for the Adding Insurances to Existing Contract function.

Expected impact BSL-CSI system:

	
- Implement function to search for Tariff Items of Sum Insured type
	
- Implement function for calculation Sum Insured based on the found Tariff Items
	
- All above-mentioned will be available for both UI and API versions of the function.


Affected Use Cases:

	
- UC08.348 Calculate Insurance offer parameters
	
- UC08.346 Add Insurance service on Contract common
