# 📋 REQ #2 - 

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-4522 (CLM-1722) New features for Insurance Service setting

## 📝 Notes

Next, it is required to have possibility to create request for insurance termination/cancellation due to evaluation this information in DWH and sharing it with the insurance company.

The business process should be as follow:

	
- Operator (call center) receive a request for insurance cancellation/termination from the client
	
- Operator create request in the system (TCK is supposed to be used here)
	
- Operator cancels/terminated insurance (possible variant: the request from step #2 will be created automatically in the TCK)
