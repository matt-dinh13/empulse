# 📋 CSI-3071 Allowed Insurance actions for operators

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/In process/CSI/CBL-22644 VAS as Add On to Existing Loan Contract - BSS ( CEL) - Enhancement

## 📝 Notes

Requirements:

	
- When VAS AddOn Insurance AMAN/INSLI is active, user/operator with role assigned should not be able to cancel the insurance AMAN via GUI (Contract detail - AddOn tab)


	
- When VAS AddOn Insurance AMAN/INSLI already active at contract, user/operator with role assigned should not be able to offer Vas additional Insurance AMAN /INSLI again. AMAN/INSLI can be offered again when AMAN/INSLI is cancelled/terminated.


Notice: operator is currently assigned to VAS_ADDON_OPERATOR
Affected use cases:

	
- 08.349 Generate Insurance offer preview
	
- 08.340 Show Insurance offers for loan contract
	
- 08.347 Add Insurance service on Contract service
