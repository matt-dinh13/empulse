# 📋 REQ#1 - New "Extend/Reactivate request" button for existing full early repayment request

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-7022 (CLM-2201) Admin function for FER request in the past

## 📝 Notes

The goal is to create a functions:

	
- to extend validity of existing FER request in status CREATED
	
- to reactivate already expired FER request in status CANCELLED


In both cases FER request execution is called called after extension/reactivation (so FER is executed if ER amount is already paired).
