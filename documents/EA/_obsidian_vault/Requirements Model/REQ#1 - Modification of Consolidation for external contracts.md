# 📋 REQ#1 - Modification of Consolidation for external contracts

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-1941 (CLM-987) External refinance

## 📝 Notes

Goal of this requirement is to be able to disburse (i.e. repayment of loans) of all client's contracts included into the consolidation which the client has in external credit companies. The client's external contracts will be excluded from the some steps of consolidation processing which make sense for internal contracts only (e.g. making FER requests, contract finishing,...)
