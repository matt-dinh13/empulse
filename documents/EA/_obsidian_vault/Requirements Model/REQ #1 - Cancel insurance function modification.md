# 📋 REQ #1 - Cancel insurance function modification

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-6857 (CLM-2177) Cancel Insurance modification function

## 📝 Notes

Goal of this task is to modify the Cancel insurance function as follow:

	
- enabling the Cancel insurance function only for Insurance Services having Service Type with MANUAL_CANCELLATION_ALLOWED flag (see UCs 11.111, 08.451, 08.452)


	
- skipping recalculation of the contract financial parameters and regeneration of the installment schedule is done when no Tariff Item related to the insurance is found (see UC 08.111)
