# 📋 REQ#1 - Exposing API for contract insurance printout

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-5348 (CLM-1919) API for Insurance printout on Contract with Signed and Active Status

## 📝 Notes

Goal of this task is exposing API for providing information about an insurance so that a documentation can be created by an external consument.

For this purpose, the following current endpoints can be used:

	
- REST /insurancecontract API for data regards the Insurance contract 
	
- REST /contract API for data regards the loan contract


Next, a new endpoint will be exposed:

	
- REST WS for providing data about Insurance Program as well as the related insurance company.
