## 📝 Notes

Provide URL for external components for displaying detail of:

	
- Product
	
- Service
	
- Tariff

URL will contain following parameters:

	
- code of entity (Product Code, etc.), mandatory
	
- version, optional

If version is not defined, then Active version is displayed.
