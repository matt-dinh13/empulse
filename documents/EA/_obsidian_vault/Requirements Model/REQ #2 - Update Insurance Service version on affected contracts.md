# 📋 REQ #2 - Update Insurance Service version on affected contracts

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-9811 (CLM-3001)[COVID19] Loan consolidation for ID

## 📝 Notes

This requirement is determined to fulfill request that insurance on the consolidated contract won't be terminated at the moment of the contract finishing. 
It will be performed by a data manipulation for change the current version of the Insurance Services on the affected contract (i.e. Contract Service) with a new one. 
Needed prerequisites of the data manipulation:

	
- A list of affected contracts for the Insurance Service version change will be provide by PH colleagues.
	
- Updating of the current Insurance service settings will be done by PH colleagues. They set the insurance to be terminated the moment the contract is finished.
