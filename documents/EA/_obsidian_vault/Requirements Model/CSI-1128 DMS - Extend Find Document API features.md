# 📋 CSI-1128 DMS - Extend Find Document API features

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CSI/CBL-12588 (CSI-545) Integrate DMS component with BSL CSI functions

## 📝 Notes

Goal of the requirement is extend the current DMS Find Document API with new search possibilities:

	
- a list of Document UUIDs (new) - the search criteria will be limited by the provided list of UUIDs
	
- a list of Document File UUIDs instead of one Doc File UUID (change)
	
- Document Type Flag (new) - the search criteria will be limited by the provided Document Type Flag
