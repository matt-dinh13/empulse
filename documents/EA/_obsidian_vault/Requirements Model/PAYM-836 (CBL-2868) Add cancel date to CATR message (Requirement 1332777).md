# 📋 PAYM-836 (CBL-2868) Add cancel date to CATR message

> **Type**: Requirement · **Stereotype**: «Epic»
> **Package**: HomerSelect/BSL/Requirements Model/In process/ISPAY/PAYM-836 (CBL-2868) Add cancel date to CATR message

## 📝 Notes

In order to do proper accounting, Book needs to have a new attribute "cancel date" for CATR (CEL Account Transaction) and CATR DN (CEL Account Transaction Disbursement Notification) messages that have typeOfOperation = CANCEL.

This attribute is to be filled with date in which the contract has been cancelled.
