# 📋 CSI-1414 Use DMS in CheckTL service evaluation

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CSI/CBL-12588 (CSI-545) Integrate DMS component with BSL CSI functions

## 📝 Notes

This requirement proposes usage of DMS module for a document management needed for UC 08.407 Evaluate CheckTL fulfillment common.
There is needed to check a Document content (file) reference existence of defined Document Type related to evaluated Contract.
Supposed integration:

	
- Get client's documents related to the Contract (COMA)
	
- Find a Document of the defined Document Type based on list of client's documents (DMS)


All mentioned changes and the current functions will be switchable
