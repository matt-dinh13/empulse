# 📋 CLM-5070 Remove navigations to CLC on shop domains

> **Type**: Requirement
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CLM-5070 Remove navigations to CLC on shop domains

## 📝 Notes

When user is on shop domain and connects from public network and wants to navigate into CLC we do display error page and log following error:

Generating unavailability URL for CLC

We should stop to generate such error and disallow user to navigate into CLC
