# 📋 REQ#2 - Create interface for calculation of Subventions from Financing Package

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/PCG/PCG-938 Financing Scheme IV - REL subventions (CBL-2621)

## 📝 Notes

Definition of Subventions on Financing Package will be used for calculation of subvention amount only for subsequent transactions (not for ICT).
Provide method for calculation of subvention amount as follows:
Input
- Financing Package (Code + version)
- Transaction Amount
- Commodity Type (optional)
Output
- Subvention Amount (Partner)
- Subvention Amount (Manufacturer)
