# 📋 REQ #2 - Exposing web service for insurance termination

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-4834 (CLM-1782) API for Insurance Cancellation and Termination

## 📝 Notes

Goal of this requirement is exposing a web service to terminate an insurance related to a loan contract
Two methods will be created for this purpose:

	
- A terminate preview method to get some information about future monthly payments after contract insurance termination and termination reasons code list
	
- A terminate contract insurance method action
