# 📋 LOR-10271 Application detail: display list of available DDM

> **Type**: Requirement · **Stereotype**: «Story»
> **Package**: HomerSelect/BSL/Requirements Model/In process/LOR/LOR-10212 Allow previously approved DDMs to be used as DDM for new Loans

## 📝 Notes

As a user, I will be able to select from list of available DDM (from earlier contracts).

Proposed solution

	
- Zeebe process will return list of DDM - now it returns only one, "latest" DDM


	
- Display list of DDM (in form of dropdown ), this list will display
- Bank Name
- Bank Account Number
- Bank Account Holder Name
	
- User will select one of available DDM
	
- System will prefill DDM data to application form
