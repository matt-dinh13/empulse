# 📋 REQ #1 - Exposing web service for insurance cancellation

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-4834 (CLM-1782) API for Insurance Cancellation and Termination

## 📝 Notes

Goal of this requirement is exposing a web service method to cancel an insurance related to a loan contract.
Two methods will be created for this purpose:

	
- A cancel preview method to get some information about future monthly payments after contract insurance cancellation and cancellation reasons code list
	
- A cancel contract insurance method action
