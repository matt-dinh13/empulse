# 📋 REQ#1 - Add previous CLIP related attributes into vector for new CLIP approval 

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-3051 (CLM-1388) Adding CLIP related attributes into vector

## 📝 Notes

The goal is to add all previous CLIP/CLDP data of the customer to vector for new CLIP approval.
Vector should contain all historical CLIP (increase) + CLDP (decrease) data for the client (for all contracts).
Fields: 

	
- Request DateTime
	
- Original Credit limit
	
- Required Credit Limit
	
- Source type
	
- Status
