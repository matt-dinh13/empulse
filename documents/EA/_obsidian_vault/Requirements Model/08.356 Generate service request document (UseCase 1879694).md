# 🎯 08.356 Generate service request document

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CSI/CBL-12588 (CSI-545) Integrate DMS component with BSL CSI functions

## 📝 Notes

A technical use case ensuring generation of a service request document. For generated document, printout is created and stored into the File Storage (Cabinet).
If a Supplement is associated to the Service, this use case is not applied for service request documents generation, but the document setting is taken from the associated Supplement and documents are created under Contract Supplements Documents - see 13.205 Create contract supplement documents
