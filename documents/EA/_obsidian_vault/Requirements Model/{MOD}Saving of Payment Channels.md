# 📋 {MOD}Saving of Payment Channels

## 📝 Notes

There is described rules to create/update of Payment Channel of Contract for particular Purpose and Type here.

Repayment channel purpose:
Saved in Contract.PaymentChannel where Purpose = 'Repayment'
Contract.PaymentChannel.PaymentChannelType is set to selected Repayment channel (e.g. 'DDM', 'Other').

Disbursement channel purpose:
Saved in Contract.PaymentChannel where Purpose = 'DI' (Disbursement)
Contract.PaymentChannel.PaymentChannelType is set to selected Disbursement channel (e.g. 'PBA').

Disbursement channel purpose for CEL reward:
Saved into Contract->Payment_Channel where .Purpose = 'RW' (CEL reward).

	
- If payment channel type (from the input) is 'OC' (On contract), then:
   - Set Contract->Payment_Channel.Type = 'OC'
   - Set Contract->Payment_Channel.Target_Contract = Contract.Contract_Code (of the currently processed contract)
	
- If payment channel type (from the input) is 'GBA' (General bank account), then:
   - Set Contract->Payment_Channel.Type = 'GBA'
   - Set Contract->Payment_Channel.Source_Type = SourceType (from the input)
   - Get Recipient_Name, Bank_Account_ID, Bank_Account_Number and Bank_Code according to the Get recipient data for Payment Channel algorithm with PaymentChannelType = 'GBA' and BankAccountId (from the input) on the input and set them onto the respective payment channel.

General notice to the payment channels storage:
Every payment channel update is historicize by following rules:

	
- The original record of the payment channel in basic table is inserted into a history table.
	
- The original record of the payment channel in basic table is updated with the new payment channel data

Goal of this solution is to ensure the outgoing payment refers to the same Payment Channel ID (i.e. it works with the current record).
