# 📋 REQ #2 - Add statistics to show my contract 

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-8291 (CLM-3246) VN - Paperless - contract Registration Queue optimization - Enhancements V3

## 📝 Notes

Goal of this task is to add labels with statistics on the screen Show my contracts:

	
- Assigned contracts for registration - number of contracts with registration task assigned to current user created today.
	
- Registered contrast for registration - number of registered contracts with registration task assigned to current user created today.
	
- Assigned contracts for Mistake investigation - number of contracts with mistake investigation task assigned to current user created today.
	
- Reported contracts with mistake - number of contracts with mistake investigation task created by current user today.


This labels are displayed only when global database parameter enhanceRegistrationQueueV3 = True.
