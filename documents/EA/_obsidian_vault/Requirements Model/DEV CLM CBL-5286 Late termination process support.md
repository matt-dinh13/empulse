# 📋 DEV CLM CBL-5286 Late termination process support

> **Type**: Requirement · **Stereotype**: «Story»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-5286 (CLM-1852) Late termination process support

## 📝 Notes

CLM Scope:
* Creation of FER request based on special ("collection") FER service which is not assigned on the contract - it can be covered by exposing API for adding FER service on a running contract and subsequently the FER request creation. This API methods will be called by Loxon after successful repayment of "shots" by a client.
* Collection FER service has to be configured properly to allow creating a request in the future and at any date.
