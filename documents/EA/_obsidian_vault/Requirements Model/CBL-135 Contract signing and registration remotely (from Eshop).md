# 📋 CBL-135 Contract signing and registration remotely (from Eshop)

> **Type**: Requirement · **Stereotype**: «Epic»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CLM-340 (CBL-135)

## 📝 Notes

Without the support for Contract Signing remotely (from HomeCredit Web or Mobile Application), we cannot fully rollout Online Cash Loan Cross-Sale and possibly some other projects such as Cash Loan Walk-in Online, E-Contract and EShop. 

That is why we want to allow our clients to read the contract in HomeCredit Web, HomeCredit Mobile Application, on E-shop page etc. directly and enable him to sign this contract electronically without necessity to go to any POS. We expect that more clients will be able to use the remote signing of contract. 

Remote signing is available in limited functionality, but activation of contract requires registration, which is not available via interface. This requirement should address these needs.
