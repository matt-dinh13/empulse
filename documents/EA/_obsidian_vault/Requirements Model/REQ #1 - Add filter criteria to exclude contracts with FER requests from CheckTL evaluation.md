# 📋 REQ #1 - Add filter criteria to exclude contracts with FER requests from CheckTL evaluation

## 📝 Notes

Goal of this tasks is to not charge penalty based on Term of Loan Service for contracts, where is created FER request. That will be accomplished by extending filter criteria for contracts evaluation of Term of Loan Service, so contracts with FER service request will be excluded and not charged with penalty.
