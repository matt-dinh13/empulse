# 📋 REQ #4 - Create a request for FER service on Contract

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/CLM/CBL-3825 (CLM-1460) Create CET/FER request in Mobile banking system

## 📝 Notes

This part of the requirement describes how to create a FER request for respective contract on an external request.
It is supposed, the user of an external application has a Contract identified, chooses a FER service which is to be used for the request, defines date of FER, and reason of the request creation.
