# 📋 LOR-8964 MFI Changes - Telesales (fields removal)

> **Type**: Requirement · **Stereotype**: «Story»
> **Package**: HomerSelect/BSL/Requirements Model/Finished/LOR/LOR-8935 CBL-18691 MFI Changes - Telesales (fields removal)

## 📝 Notes

Proposed solution:

	
- removing of net income field from 0BoD and 2BOD and 1SP app forms
	
- renaming of household income to monthly household income field - for ALL applications and this field has to be presented on ALL app forms
	
- removing the logic for displaying of household income based on marital status and value of income (it will be removed from ALL applications)
	
- removing of Sales Agent number field from ALL applications
