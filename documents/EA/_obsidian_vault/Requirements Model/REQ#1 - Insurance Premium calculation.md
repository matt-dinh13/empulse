# 📋 REQ#1 - Insurance Premium calculation

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Requirements Model/In process/CSI/CBL-31227 (CSI-4312) Adding Insurance to Active Contracts - Insurance Premium calculation

## 📝 Notes

Goal of the requirement is extending calculation of Insurance Premium amount (Tariff Item) based on Product catalogue Tariff Item parameters for the Adding Insurances to Existing Contract function.

There are especially asked following parameters of the Tariff Item configurations:

	
- Percentage Based on: Whole Principal || Financed Amount
	
- All other Tariff Item parameters intended for fee calculations


Expected impact BSL-CSI system:

	
- Implement function for Insurance Premium calculation based on the found Tariff Items
	
- All above-mentioned will be available for both UI and API versions of the function.
