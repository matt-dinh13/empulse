# 🎯 01.220 Search for contract package

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Contract package tracking/Access Rights

## 📝 Notes

This use case enables the users to find contract package that match entered criteria. Result with basic details is shown. For each shown contract package is available use case << UC 01.230 Show contract package details >>. 

'Search for contract package' screen is opened with focus on 'Contract package code' input field. This field will be configured to accept also contract package bar code as search criterion (since only difference is that barcode will contain prefix CP). After user scans barcode with focus in this field search will be triggered, system will extract CP code from barcode and will try to find contract package.
