# 🎯 08.900 Show available collection tools for client's contracts

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Collection tools support/Collection tools requests/Access Rights

## 📝 Notes

The use case describes evaluation and displaying collection tools available for client’s contracts.
Collection tools are presented by Loan Services marked as “collection tool service”. If a service is not available for the contract (Contract Service object does not exist for the contract) but the contract Product has this service currently associated, the service is added to the contract for follow-up usage. Keep in mind, such loan service has to be set as mandatory on the product to be added to contract services.
