# 🎯 08.408 Set terms of loan fulfillment

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Checking Terms of Loan Service/Access Rights

## 📝 Notes

The use case allows a user to set a result of fulfillment of some defined terms of loan. Now, the fulfillment regards delivering a defined document by client. Document is defined on the Checking Terms of Loan Service and the fulfillment of this request for the document delivering is set on a Loan Service Request of this Service.
If "MPF_Invoice" document was uploaded for contracts with charged penalty that has not been paid yet then penalty is waived.
