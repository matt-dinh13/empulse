# 📋 Reset button in search forms

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Analysis Model/_General Rules/System behavior

## 📝 Notes

When reset button in a search form is used, then all values inserted in input fields are set to default values (empty when default value is not specified). If results were displayed before use of reset button, then they are removed as well.
