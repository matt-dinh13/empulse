# 🎯 13.070 Process Credit limit change request via messaging

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/Credit limit change support/Access Rights

## 📝 Notes

This use case present processing of credit limit change requests (single/bulk) for REL contracts.
The requests are received via messaging. For each request for credit limit change, there is Contract Supplement object created in the system and processed based on Supplement definition.

Notice:
In the future, this use case should replace the current UC 13.050 Process credit limit change request (bulk file request) and possibly 13.055 Increase credit limit on external request (single web request)
