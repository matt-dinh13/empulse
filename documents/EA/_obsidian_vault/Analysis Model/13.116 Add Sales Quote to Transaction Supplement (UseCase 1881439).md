# 🎯 13.116 Add Sales Quote to Transaction Supplement

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/Transaction Supplement support/Interface Provided/Web Services/TransactionSupplements/TransactionSupplements_v1

## 📝 Notes

The use case presents a method for adding defined Sales Quote to the Transaction Supplement. In case the Sales Quote contains an item should be charged (e.g. a service with charged fee), a account transaction is created as well.

Call example:
https://bsl.in00a1.cz.infra/bsl/api/v2/transaction-supplement/sales-quote
{
  "contractServiceId": "string",
  "dealCode": "string",
  "masterTransaction": true,
  "parentSalesQuoteId": "string",
  "paymentChannelId": "string",
  "salesQuoteId": "string",
  "transactionSupplementId": "string"
}
