# 🎯 01.135 Get information about document from document archive

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract documents management/Access Rights/Contract documents

## 📝 Notes

Information about uploaded documents must be visible, if document copy was uploaded into document archive - it means document has UUID (Document archive identification) record in database.
In such situations BSL must call document archive (Cabinet) to obtain all information about document versions and display information about newest one. When user clicks on icon the list must be expanded on contain information about all versions sorted from newest to oldest.
