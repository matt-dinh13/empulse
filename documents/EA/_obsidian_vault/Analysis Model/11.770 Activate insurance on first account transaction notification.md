# 🎯 11.770 Activate insurance on first account transaction notification

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Insurance/Insurance Contract/Access Rights

## 📝 Notes

-- meaning of this use case is to reuse it for future Insurance module
This use case describes how notifications about the first (initial) transactions generated by Cabus AM are processed in Insurance. In short, the following steps are performed:

	
- set start of the insurance(s) assigned to the contract
	
- activate insurance contracts
	
- create insurance outgoing payments
