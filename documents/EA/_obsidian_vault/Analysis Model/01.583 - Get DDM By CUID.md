# 🎯 01.583 - Get DDM by CUID

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Mandate (DDM)/DDM via WS/Access Rights

## 📝 Notes

This technical use case describes processing of behavior of getting information about retrieving correct DDM.
System calls method DirectDebitMandates.getDDMInfo(), which find all DDMs from all clients contracts.
If condition ShowDDM = 'LAST_ACTIVE_DDM', then system returns DDM with at least one debited DDS with the latest creation_date.
If condition ShowDDM = 'ALL_DDM', then system returns all created DDMs.
