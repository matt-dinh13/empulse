# 🎯 05.030 Couple incoming payment manually

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Incoming payments/Pairing incomming payments/Access Rights

## 📝 Notes

User executes this UC to manually couple selected incoming payment with corresponding contract and its installments. 
User specifies contract the selected payment should be paired with and the system performs coupling of the selected payment with specified contract and its installments. If the payment is older than any already contract paired payment, re-coupling of the current payments has to be performed. 
As a part of pairing the following reactions are invoked: 
- checking and processing of Full early repayment,
- checking and processing of Grace period.
