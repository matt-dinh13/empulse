# 📋 Data refresh after insert or update a records

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Analysis Model/_General Rules/System behavior

## 📝 Notes

If data is inserted or modified into a modal screen and this data is also presented in a parent screen, the parent screen has to be refreshed with new/changed data.
