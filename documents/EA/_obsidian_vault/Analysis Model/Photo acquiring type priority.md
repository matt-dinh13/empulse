# 📋 Photo acquiring type priority

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/COMMON for Fill in application/User Interface Model/COMMON for User Interface/Document panel

## 📝 Notes

When some document type is assigned to multiple document containers applicable for the selected product and the Photo acquiring type in such document containers differs, then system selects the applicable photo acquiring type according to the following priority:

	
- PCM
	
- PUM
	
- PIM
	
- PCO
	
- PCU
	
- PD
