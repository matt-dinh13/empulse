# 🎯 03.200 Show ER request history

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/COMMON for Early Repayment/Access Rights

## 📝 Notes

This use case describes work scenario with history of already created Loan Service Request of FER, PER, CET, COP types with Early repayment extension related to a client.
If there exists a ER request of the client, user can open a screen with a list of already created requests - see ER requests history
If a printout has been created to a ER request, user can print that - see 03.210 Print ER document use case.

Frequency of usage:
   A few requests a day created by back-office operators
Actor:
  Authorized user
