# 🎯 13.450 Process supplement approval result

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/Credit limit change support/Access Rights

## 📝 Notes

Purpose of this technical use case is to receive result of evaluation from the LAP for approval processes of requests where Supplement is used (e.g. CLIP, Loan restructuring service). A request for approval is sent by UC 13.150 Send supplement to approval into LAP system. After a result receiving, system stores necessary result information, change status of request (supplement) accordingly and performs some steps by type of the request.
Additionally, ZeeBe orchestration can be used for integration between BSL and LAP for the CLIP approval process.
After the response processing it is continued according the result of the approval.
