# 🎯 03.040 Print selected version of IS

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Installment Schedule/Installment Schedule/Access Rights

## 📝 Notes

The use case describes how to print selected version of the installment schedule (IS). The action can be run by user from the Installment schedule user interface.
First, it is checked if the chosen version of IS has a printout document already stored. If so, the printout is obtained from the document storage (Cabinet). 
If  no printout is found and requested IS printout has to be stored in the system, it is generated a new printout by the help of 03.045 Generate IS printout use case and offered to user to print.
If  no printout is found and requested IS printout is not intended to store in the system, it is only generated IS printout.
Finally, the IS printout is offered to user to next processing.
