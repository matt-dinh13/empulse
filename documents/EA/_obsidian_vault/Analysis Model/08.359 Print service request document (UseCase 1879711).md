# 🎯 08.359 Print service request document

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/COMMON for Loan Services/Access Rights

## 📝 Notes

This use case describes a print of a request document for a loan service. In order to the print be performed, there is needed to define a document type as well as printout template for the particular loan service.
If the document and its print template are defined, the printout (PDF document) is generated and stored in the system within a service request creating by calling 08.356 Generate service request document use case. If more documents are defined for the service request, all printout documents are generated into one PDF document.
Before the document printing, the user determines the contract for which the service request is created. Next, user determines service request to print in the list of service requests history. (Notice: the Print service request document action is enabled only if a document exists).
Finally, the system gets particular printout from the File Storage (Cabinet) and offer to user to downloading and printing.
