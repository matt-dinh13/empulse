# 🎯 11.110 Cancel insurance contract

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Insurance/Insurance Contract/Insurance finishing/Access Rights

## 📝 Notes

This technical use case cancels insurance contract as such.
Following is done:

	
- Insurance contract status is set to CANCELLED, status reason - both enumerated and free text - is set.
	
- All insurance periods are cancelled
	
- End Date is set to given date of cancellation.
