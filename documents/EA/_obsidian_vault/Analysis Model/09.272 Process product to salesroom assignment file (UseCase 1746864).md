# 🎯 09.272 Process product to salesroom assignment file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Sales Network Management/Salesroom/Products on Salesroom/User Interface

## 📝 Notes

This technical, non-visual use case is used to process already imported file with instructions for assignment of products to salesrooms. Processing is done separately for each instruction so it's possible to process file partially (i.e. correct instructions will be processed, invalid won't be processed). When processing ends, then user who uploaded file is informed about result.
Structure of input file with instructions for assignment and output files with correctly processed/unprocessed instructions is described in diagram Structure of files for import of assignment of Product to Salesroom.
