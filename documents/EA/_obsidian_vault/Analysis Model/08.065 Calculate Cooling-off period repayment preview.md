# 🎯 08.065 Calculate Cooling-off period repayment preview

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Cooling-off period/Access Rights

## 📝 Notes

This functionality allows user to get information needed to the early repayment of loan under cooling-off period in case a client asks for it. The ER preview calculation is done over one selected contract, following steps are performed:

	
- automatic selection of suitable date of cooling-off ER
	
- calculation of all needed amounts for ER
	
- checking of ER request under cooling-off period availability
