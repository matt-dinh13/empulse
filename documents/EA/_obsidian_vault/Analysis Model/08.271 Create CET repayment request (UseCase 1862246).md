# 🎯 08.271 Create CET repayment request

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Contract Early Termination/Access Rights

## 📝 Notes

Use case is activated from the CET repayment preview (08.270 Show CET repayment preview).
After the client is familiar with amounts and accept conditions for the Contract Early Termination (CET), it is possible to create request for CET. Request contains information about amount which needs to be paid and the last date (expiration date) when this amount has to be paid.
Notice: This function is used for creating a new ER request. If you interested in browsing already created ER requests - see 03.200 Show ER request history.

Frequency of usage:
   A few requests a day created by back-office operators
Actor:
  Authorized user
