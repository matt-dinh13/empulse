# 📋 01.592 Cancel paid-off contract manually

> **Type**: Requirement · **Stereotype**: «Access Right»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract cancellation/Access Rights

## 📝 Notes

Basic access right for UC activation
Code=UC01_592
Rule Access control to Contract by Salesroom is applied; user can access only contracts which were signed on the Salesroom where the user is logged on or no restriction if Contract.Created remotely = true.

Salesrooms where the contracts were originated are get according to the rule Get salesroom by operation, passed is Contract and operation = CONTRACT_SIGNED.
