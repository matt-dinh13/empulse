# 🎯 13.361 Cancel contract supplement automatically

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/COMMON for Supplements/Contract Supplement operations/Contract Supplement management/Access Rights

## 📝 Notes

Purpose of this use case is to find contract supplements that are too long in a status and cancel them (this characteristic feature is not determined dynamically, but it is stored as "Timeout cancellation" on revolving transaction supplement). This is implemented as a planned action - see job rule definition CONTRACT_SUPPLEMENT_AUTO_CANCEL

Note: This use case currently changes only the status of contract supplements. If any other influence is necessary (e.g. calling Cabus due to cancellation of performed changes), this use case has to be extended.
