# 🎯 01.730 Finish contract manually

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract finishing/Access Rights

## 📝 Notes

The use case describes functionality to finish a contract by user. (For automatic finishing of contracts see 01.710 Process contracts to finishing)
First, it is checked if all the contract installments are paid. A debt tolerance is accepted as well as possibly “small underpayment” is solved here.
Next, if some services are allowed on the contract, system tries to evaluate and process a service with the highest priority.
Finally, contract is transferred into the Finished status with information that it is manual status transfer.

Notice to a service evaluation:

	
- GIFTP - if the client asks for contract finishing before the GIFTP can be applied (before Gift payment date), GIFTP is not granted at moment of the service evaluation
	
- GRPER, FER and CET - in case of these services, an evaluation makes sense only if these service are set for processing exactly on ER due date


Notice to an insurance related to the finished loan contract:

	
- Insurance contract is terminated at the moment of manual contract closure only in case flag Insurance Service.Terminate on Full Repayment == True
{ADD CSI-3782 PH} OR Service.Terminate on Full Repayment == FALSE AND Service.Terminate on unpaid premium == True AND (insurance premium is still under the coverage period AND (insurance premium is not paid OR (insurance premium is paid AND insurance period is finished))){/ADD}
Otherwise insurance service stays valid to the end of agreed insurance period.
