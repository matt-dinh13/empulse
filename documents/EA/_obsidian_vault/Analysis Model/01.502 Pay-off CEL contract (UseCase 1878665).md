# 🎯 01.502 Pay-off CEL contract

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract pay-off/Access Rights

## 📝 Notes

This technical, non-visual use case is used to pay-off of selected contract. 
The pay-off of CEL contract is performed synchronously (immediately). After a check payoff possibility, the termination is performed and this use case returns information about termination (successful or not) back to the collection system by calling TerminationStatusService.
Originally excluded from UC 01.501 Pay-off contracts from external system
