# 🎯 00.010 Set user options

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/COMMON for BSL/User settings/Access Rights

## 📝 Notes

This functionality allows user to set his preferences regarding system. Changes done in these settings will influence behavior of system in its different parts.
User can set application language, which defines in what language labels and texts will be displayed. User can optionally set active salesroom, which defines restrictions mainly in contract management (i.e. user has to have set active salesroom to be able to create contracts). When user has special right, he can set sales agent. This agent is referenced as sales agent who has created contract, when user contract creates. When sales agent is set, only active salesroom of this agent can be set as active salesroom for the user. User can also optionally set active sales area, which defines restrictions mainly in contract management (i.e. user can display only contracts signed in set sales area, export/import DDM only of contract signed in selected area).

Following user option are enabled:

	
- Setting Active salesroom
	
- Setting of application form language
	
- Sales agent registration
	
- Setting active sales area


Starting point: This use case can be executed from Menu
