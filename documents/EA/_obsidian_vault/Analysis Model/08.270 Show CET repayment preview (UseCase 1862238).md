# 🎯 08.270 Show CET repayment preview

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Contract Early Termination/Access Rights

## 📝 Notes

This functionality allows user to get information needed to the contract early termination (CET) of loan in case a client asks for it.
The preview is done over one contract selected by the user.
During this action, following steps are performed:

	
- user chooses decisive date and variant of CET
	
- system calculates all needed amounts for CET

Finally, calculated ER amounts are displayed on the screen and operator can inform the client about result. 
User can continue with UC 08.271 Create CET repayment request.  

Frequency of usage:
A few requests a day created by back-office operators

Actor:
Authorized user
