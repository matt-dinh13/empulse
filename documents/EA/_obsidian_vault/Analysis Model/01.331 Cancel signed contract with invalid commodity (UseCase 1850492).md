# 🎯 01.331 Cancel signed contract with invalid commodity

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract cancellation/Access Rights

## 📝 Notes

Purpose of this use case is to find contracts in status 'Signed' with commodity which is not validated into a defined time and cancel them. Contract is canceled if at least one Commodity is invalid.
The use case is run by regular automatic job - see {ADD}Cancel signed contract with invalid commodity. The job is running only if Global Parameters.InactivityOfNonValidatedSignedContract >0 or is not NULL.
