# 🎯 01.155 Generate optional offers

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Manage Product Offer/Access Rights

## 📝 Notes

This non-visual use case describes how optional offers are generated by the system. 
The algorithm used for generation of optional offers is the same as algorithm for generating of primary offers. The system does not distinguish if it is calculating positive or negative offers. 
The use case has the following basic steps:

	
- The system (BSL) receives offer specifications defined by Blaze
	
- The system loads other necessary information
	
- The system finds potential optional offers, sorts them and returns them
