# 📋 Mask fields rule for AUI - VN

> **Type**: Requirement · **Stereotype**: «Business rule»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/COMMON for Fill in application/Business Rules/VN

## 📝 Notes

This rule describes how fields are masked in application form, client search screen and client detail search screen in VN.
 

	
- PRIMARY_EMAIL - mask all characters in user part  except the first 2
	
- ID_CARD - mask all the characters except the last 3 number
	
- FAMILY_BOOK - mask all the characters except the last 3 number
