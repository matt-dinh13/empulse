# 🎯 11.121 Terminate insurance contract manually

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Insurance/Insurance Contract/Insurance finishing/Access Rights

## 📝 Notes

This use case describes how to terminate insurance contract (and service). Termination means finishing an active insurance related to a loan contract at some date. User can terminate the insurance independently on the loan contract itself. 
The insurance cannot be terminated to the past (retrospectively).
Notice to system events generation:

	
- ContractServiceChangedSE: it sends ContractFullInfoRequest message
	
- InsuranceContractTerminationSE: it sends InsuranceTransactionRequest message (subscribed by BOOK NG)
