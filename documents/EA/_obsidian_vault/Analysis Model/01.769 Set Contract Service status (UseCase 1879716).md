# 🎯 01.769 Set Contract Service status

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Customer Self-Care API/Access Rights

## 📝 Notes

The use case describes updating Contract Service status on an external request.
Contract Service has to be in status NEW to be the request successful. Also Contract related to the Contract Service has to be in one of allowed statuses.
endpoint address example: /v1.0/contractservices/{serviceId}/status
