# 🎯 01.116 Set client document security level

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract documents management/Access Rights/Client documents

## 📝 Notes

Steps:

	
- User opens detail of a contract (see UC 01.210 Show contract detail) and select a document for setting security level
	
- System displays the Set document security level modal window  (Set document security level / Set document security level).
	
- System calls function Populate security level select box options to populate security level select box.
	
- User selects security level and confirms.
	
- System calls UC 01.117 Set document security level common
- if  an error is returned, system displays error message and use case ends.
	
- System closes the modal window.
	
- Use case ends
