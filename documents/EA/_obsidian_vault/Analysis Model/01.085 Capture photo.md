# 🎯 01.085 Capture Photo

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/Photo component/Access Right

## 📝 Notes

This use case is used to capture photo of client or document. Use case also allows to re-capture photo in cases, when picture is of a bad quality (doesn't pass internal quality validations) or when user decides to do so for any reason. User is able to see preview of photo before it is captured as well as the last captured picture.

	
- When photo of the client (or other person) should be taken, photo component with Photo capture mode = "Person" as parameter is called.
	
- When photo of the document should be taken, photo component with Photo capture mode = "Document" as parameter is called.


Note:
If user has photocomponent simulator enabled (value of setting User->User_Setting[.User_Setting_Item='PHOTOCOMPONENT_SIMULATOR'].Value is set to TRUE), above use cases are not invoked and photo from simulator is returned.
