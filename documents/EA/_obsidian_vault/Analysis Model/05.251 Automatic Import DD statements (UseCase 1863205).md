# 🎯 05.251 Automatic Import DD statements

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Statements/Access Rights

## 📝 Notes

External system executes this use case to import file containing DD statements exported from DWH or DD statements confirmations received from bank. External system call web service. System then creates asynchronous job and performs import of selected file.

Variant of Import DD files use case for import of DD statements.

See UC {05.140 Import DD files} for scenario. Scenario uses this specific settings:
