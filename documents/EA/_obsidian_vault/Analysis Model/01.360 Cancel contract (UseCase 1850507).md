# 🎯 01.360 Cancel contract

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract cancellation/Access Rights

## 📝 Notes

This is a purely technical use case describing which actions have to be performed when a contract is required to be moved to status 'Canceled'. All the steps are (and must be) independent of current status of the contract, however several steps can have no effect.
