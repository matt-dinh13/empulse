# 🎯 01.015 Manage application cancellation configurations

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Application cancellation configuration/Access rights

## 📝 Notes

This use case enables the user to manage the  application cancellation configurations. This includes the following operations:

	
- Search for the particular configurations.
	
- Create new configuration.
	
- Display the detail of selected existing configuration.
	
- Update the attributes of existing configuration.
	
- Deactivate the existing configuration, that shall not be further applicable.
