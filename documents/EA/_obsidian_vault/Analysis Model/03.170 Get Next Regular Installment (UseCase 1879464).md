# 🎯 03.170 Get Next Regular Installment

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/_Interface/Provided Web Services/Installment Schedule/Installment schedule/InstallmentScheduleRestAPIv1_new

## 📝 Notes

This technical, non-visual use case is used to find and return information about the next (after today or another specified date) regular installment and its parts. By word "regular" are meant those installments which were created at contract signature and contain principal and/or interest. Penalties and stand-alone fees aren't taken into account by this use case. 

Functionality works only with active installments.

This functionality is used by external systems such as Collection system and provided through appropriate BSL interface.
