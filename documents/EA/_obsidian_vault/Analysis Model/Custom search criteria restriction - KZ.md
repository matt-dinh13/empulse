# 📋 Custom search criteria restriction - KZ

> **Type**: Requirement · **Stereotype**: «Validate»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract search/Validation rules

## 📝 Notes

At least one of the following rules must be met:

	
- Rule1: Last name, Created from and Created to are mandatory
	
- Rule2: Contract Number is mandatory
	
- Rule3: National Identification Number is mandatory
	
- Rule4: Birthday, Lastname, Created from and Created to are mandatory
