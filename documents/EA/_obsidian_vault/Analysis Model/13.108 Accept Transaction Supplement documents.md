# 🎯 13.108 Accept Transaction Supplement documents

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/Transaction Supplement support/Access Rights

## 📝 Notes

The use case present function for acceptance (sign) of Transaction Supplement documents. If the document is accepted, process continues with creation transaction (of respective type) and sending to the AM for authorization.
If the document is rejected, the Transaction Supplement is canceled.
The use case is called via exposed web service

Example of the request: PUT <bsl_env>/bsl/api/v1.0/transaction-supplement/acceptance
{
   "transactionSupplementId":"40000012640058",
   "clientResponse":"ACCEPT",
   "verificationData":{
      "verificationCode":"1239",
      "contactNumberVerification":"708123456",
      "verificationDate":"2020-08-31"
   }
}
{
   "requestId":"40000012640022",
   "clientResponse":"REJECT"
   "reasonCode":"ALOP_REJECTED_BY_CLIENT"
}
