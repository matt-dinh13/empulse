# 🎯 05.300 Import disbursement confirmations

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Outgoing payments/Disbursement confirmation/Access Rights

## 📝 Notes

User executes this use case to import confirmations about receiving of payments by clients. The confirmations are presented by records an external file of standardized XML format. For the file structure description see DisbursementConfirmationFile. 
User selects one file for import from a directory - see Import disbursement confirmation file screen model.
System performs validations set of validation (Maximum file size, File duplicity) for the chosen file.
If validation passes, system runs import of data from the file to the system as asynchronous process - see 05.310 Process disbursement confirmations use case.

Frequency of usage:
Several times a day
Actor:
User role authorized to run the UC
