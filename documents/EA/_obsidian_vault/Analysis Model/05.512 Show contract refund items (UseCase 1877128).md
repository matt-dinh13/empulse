# 🎯 05.512 Show contract refund items

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Refunds/Refund management/Access Rights

## 📝 Notes

The purpose of this use case is to display all refunds belonging to passed contract. 
On the form is refund overview as well as grid with particular refunds with which the user may perform following operations:

	
- Cancel particular refunds
	
- Generate outgoing payment for selected refunds


On the form the user also may run editing of refund disbursement method.
