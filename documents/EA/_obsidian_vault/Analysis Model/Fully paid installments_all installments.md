# 🖥️ Fully paid installments/all installments

> **Type**: GUIElement · **Stereotype**: «text»
> **Package**: HomerSelect/BSL/Analysis Model/Installment Schedule/Installment Schedule/User Interface Model

## 📝 Notes

Mandatory: No
Editable: No

Displays count of fully paid installments (Installment_Parts.Fully_Paid_Date not NULL) along with all installments where Installment.Installment_Type = ‘STANDARD’. Example:
- 5 of 15 insatallments already paid will be displayed as 05/15

Localization code: INS_FullyPaidVsAllInstallments
