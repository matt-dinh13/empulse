# 🎯 03.100 Check and process Early repayment request

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Full Early Repayment/Access Rights

## 📝 Notes

System executes this use case to check if an Early repayment request exists to the contract. The use case is called in case of:

	
- change balance on the contract occurred (pairing payment, unpairing payment)
	
- an early repayment request is created

If more ER requests exist on the contract, system takes the first active one. System calculates remaining amount for ER - see 03.070 Calculate early repayment amount use case. Next it is checked if the client payments are sufficient to cover all unpaid debt. If so, the early repayment of installment schedule is performed - see 03.110 Perform early repayment installment schedule use case. 
Finally, system sets the ER request as fulfilled.
