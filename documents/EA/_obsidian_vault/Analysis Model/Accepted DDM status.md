> **Type**: Class
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Statements/Logical Data Model

## 📝 Notes

This entity is used to configure set of DDM statuses which are considered as good enough to allow system to create DD statements based on DDMs in that status. A multi-level configuration is possible.
