# 🖥️ Hours

> **Type**: GUIElement · **Stereotype**: «combobox»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/COMMON for Fill in application/User Interface Model/Product/Queue control panel - product AF

## 📝 Notes

Hours when the re-scheduled call should take place (24-hour type). Chosen from combobox.
Combobox contains values from workingHoursStart to workingHoursEnd (global parameters).  
For example, if workingHoursStart = 7 and workingHoursEnd = 23, the combobox contains values from 07 to 23.

Pre-filled by currently planned values (Application_Filling_Queue.Contact_Date_And_Time (time:hours part)).

localization code: APP_2BODPreferredContactHours
