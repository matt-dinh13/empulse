## 📝 Notes

Search input field for filtering the communication records displayed in the Communication records grid based on the entered free-text expression - only the records, which contain the respective expression in any of their attributes (represented by the grid's columns) are kept being shown; the rest is filtered out (see the 07.022 Show list of communication for application / 07.020 Show list of communication use case for more details).
