## 📝 Notes

The value is divided into two parts. Between these parts must be underscore(ASCII 95). 
First part must be identifier of existing salesroom 
authorized user has to be assigned to salesroom in HSIS system
Second part has only digits 0-9.
Length of full string is maximum 30 chars.
