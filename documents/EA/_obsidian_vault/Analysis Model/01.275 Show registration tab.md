# 🎯 01.275 Show registration tab

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract registration/AccessRights

## 📝 Notes

Note: Renamed from Show contract registration

Purpose of this use case is to display contract or supplement registration tab. When the tab is opened it contains:

	
- Client's photo (If it is available)
	
- Documents required for registration
	
- List of recorded document mistakes (Contract mistake tickets) under every document, with list of 'Set ticket state buttons'


In this screen users may:

	
- Check presence of single document  (only if Registration status of contract is NRR or RR) - via checkbox Check (if user has additional access right 01.275 Show contract registration - check presence of documents) or via  scanning document's barcode (additional access right 01.272 Check presence of document with barcode reader)
	
- Check presence of all documents  (only if Registration status of contract is NRR or RR) - via checkbox Check all (if user has additional access right 01.275 Show contract registration - check presence of all unchecked documents).


	
- Record new document mistakes (only if Registration status of contract is NRR or RR) - Recording of document mistakes is performed via UC 01.280 Record mistakes and is allowed only for user with basic access right
	
- Change state of recorded document mistakes - this is performed through clicking on a 'Set ticket state button' (see alternative flow of UC 10.060 Change state of ticket)
	
- Register the contract (only if Registration status of contract is NRR or RR, if all critical mistakes are in state Closed or Canceled and presence of all required documents is checked) - see UC 01.270 Register contract
