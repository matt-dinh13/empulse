# 🎯 08.066 Calculate Full Early repayment preview

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Full Early Repayment/Access Rights

## 📝 Notes

This functionality allows user to get information needed to the early repayment of loan in case a client asks for it.
The ER preview calculation is done over one selected contract, following steps are performed:

	
- automatic selecting of suitable date of ER - see 03.060 Calculate early repayment date
	
- calculation of all needed amounts to ER - see 03.070 Calculate early repayment amount
	
- checking of ER request creating action availability - see Check ER request availability. The check is performed on basis of the service setting. If the client's contract does not fulfill rules for ER, the ER request creating action is not allowed.
