# 🖥️ CEL reward channel

> **Type**: GUIElement · **Stereotype**: «panel»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Application detail/User Interface Model/Tab - Payment channels

## 📝 Notes

Panel containing the basic information about the CEL reward channel connected with respective application as well as the operational buttons for related operations.

Visible only if one of the following conditions is met:

	
- CEL reward payment channel of general bank account type (GetPaymentChannelResponse.paymentChannels.purpose = 'RW' and .type = 'GBA') exists on the application.
