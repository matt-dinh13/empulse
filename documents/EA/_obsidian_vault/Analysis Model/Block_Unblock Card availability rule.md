# 📋 Block/Unblock Card availability rule

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Analysis Model/Card management support/Card operations/Business rules

## 📝 Notes

Card must be in one of these statuses:

	
- ACTIVE
	
- BLOCKED
	
- LOST
	
- STOLEN
	
- DETAIN
	
- CANCELLED


 

and account must be in one of these statuses:

	
- AC
	
- PCL
