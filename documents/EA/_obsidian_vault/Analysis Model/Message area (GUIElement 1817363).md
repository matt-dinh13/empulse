# 🖥️ Message area

> **Type**: GUIElement · **Stereotype**: «form»
> **Package**: HomerSelect/BSL/Analysis Model/COMMON for BSL/General parts of the application

## 📝 Notes

Message panel is used to show messages (especially validation ones) to the user. Message panel is shown above the working area and it is displayed only when it contains at least one message. It’s never shown empty. Message panel doesn’t contain any active control items (such as buttons) but it can contain links to fields that are invalid.
