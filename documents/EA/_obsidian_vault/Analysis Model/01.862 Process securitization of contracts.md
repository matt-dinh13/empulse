# 🎯 01.862 Process securitization of contracts

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract securitization/Access rights

## 📝 Notes

This use case is planed very close to midnight.

It processes all unprocessed tranches with sales date lower than the time of the job launching.
For each item the system calls the use case 01.863 Perform contract securitization.

Having all item processed, the system marks the tranche as successfully processed and the SecuritizationTrancheProcessedSE system event is generated. 

Frequency of usage:
Daily after midnight.

Job running constraint: 
This job can be run only after finishing a job 01.475 Update overdue debt in job.
