# 🎯 13.150 Send supplement to approval

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/COMMON for Supplements/Contract Supplement operations/Contract Supplement approval/Use Case Model

## 📝 Notes

This technical use case describes set up LAP data vector and generating message in order to sending of request (presented by a supplement to contract) to approval.
Result of the approval is caught by UC 13.450 Process supplement approval result
Additionally, ZeeBe orchestration can be used for integration between BSL and LAP for the CLIP approval process.
No access right is implemented for this UC.
