## 📝 Notes

The use case creation of a request for loan restructuring (CEL products only). 
First, standard validation for service eligibility are performed. Next, the created request with other loan/contract parameters goes to approval process (LAP).
If the service has blocking evaluation Gift and Grace services set, evaluation of these bonus services is paused.
