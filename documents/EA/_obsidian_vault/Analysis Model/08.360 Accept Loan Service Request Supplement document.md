# 🎯 08.360 Accept Loan Service Request Supplement document

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Collection tools support/Collection tools management/Access Rights

## 📝 Notes

The use case present function for acceptance (sign) Supplement documents related to the Loan Service Request. If the document is accepted, process continues with Loan Service Request execution.
If the document is rejected, the Loan Service Request and related supplement is canceled.
The use case is called via exposed web service

Example of the request: PUT <BSL_ADDR>/.../loan-service-requests/acceptance
