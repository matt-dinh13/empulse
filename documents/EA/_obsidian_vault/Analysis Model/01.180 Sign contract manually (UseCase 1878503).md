# 🎯 01.180 Sign contract manually

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Contract signing/Access Rights

## 📝 Notes

Purpose of this use case is to confirm the credit documents signature and perform steps that are related to this event:

	
- check that documents to sign are prepared and signed until end of it's validity. If this rule is not fulfilled, system asks user if he wants to continue even so. If not, user could to generate entire credit documentation again (see 01.182 Prepare documentation to sign use case)


	
- check all document existence validations and validations of all document types


	
- validate the contract commodities
	
- create the current account in external banking system, when respective IBAN was previously reserved for the contract


	
- Call technical use case 01.187 Sign contract
