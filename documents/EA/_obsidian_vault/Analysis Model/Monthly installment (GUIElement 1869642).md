# 🖥️ Monthly installment

> **Type**: GUIElement · **Stereotype**: «lradio»
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Mandate (DDM)/Create/Update/Receive DDM/User Interface Model/IN

## 📝 Notes

Default for create and update:
Unchecked.

Editable:
Field is editable for create and update of DDM.

Visibility:
Field is visible for create and update of DDM.

When this field is checked by user, fields Credit amount and Same as last DDM are unchecked and field Limit is filled in with value of monthly installment (Financial_Parameters.Total_Monthly_Payment).

Localization: 
PRD_InstallmentAmount
