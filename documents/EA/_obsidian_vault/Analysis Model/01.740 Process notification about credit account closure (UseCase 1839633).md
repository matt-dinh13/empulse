# 🎯 01.740 Process notification about credit account closure 

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Account management/Credit account notification processing/Access rights

## 📝 Notes

This use case describes processing of request obtained during calling AccountNotificationWS.ProcessAccountClosureResult() by external system (e.g. by CaBus). BSL can process different requests by this use case. 

For account termination one action can occur:

	
- Account termination has been processed successfully (TERMINATION_SUCCESSFUL) - the contract is marked as finished (there can be created a refund of overpayment as well) as well as the termination request
	
- Account termination has not been processed successfully
(TERMINATION_UNSUCCESSFUL_SEIZED) - account is seized (arrest) so it can not be closed then business event is created about this notification
	
- Account termination has been expired - the Termination request is marked as EXPIRED


For account cancellation three situations can occur:

	
- Account cancellation has been process successfully - system cancels the contract.
	
- Account cancellation has not been process successful - the contract is not canceled.
	
- Account had been canceled before - system cancels the contract.


Note: 
Currently is this use case used only for processing account closure for REVOLVING accounts.
