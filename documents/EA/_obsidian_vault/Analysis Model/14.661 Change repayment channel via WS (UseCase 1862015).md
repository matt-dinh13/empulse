# 🎯 14.661 Change repayment channel via WS

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Mandate (DDM)/DDM via WS/Access Rights

## 📝 Notes

This technical use case describes processing of behavior of changing repayment channel of contract. 
System call method PaymentChannelWS.ChangeRepaymentChannel(), which change repayment channel for chosen contract. In case of change repayment channel to Direct Debit, system checks if DDM is created.
