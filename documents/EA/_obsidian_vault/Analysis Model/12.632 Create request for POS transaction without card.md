# 🎯 12.632 Create request for POS transaction without card

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Account management/Cardless transactions support/User Interface Model

## 📝 Notes

The use case describes a system support for creation a Repeated POS (cardless) transaction on a request of client.
The action is run by the loan origination process when a client asks for financing of some goods (commodity), SA/RA finds out the client has REL contract and offers him/he financing the goods via REL contract as cardless transaction.
After commodity data entering confirmation (one commodity is possible to enter for now),  the commodity data is sent to storage and installment plan offers suitable for the loan are showed.
Operator chooses one offer (based on client's preference) and confirm that. Proofing of the client is performed via the one time password (OTP). If a correct password is entered, the transaction is sent to the Account management to authorization. The UC evaluates the returned response and inform the operator.

Keep in mind, a RELIP service (Installment Plan for REL transaction) has to exist on the contract to perform the action!
