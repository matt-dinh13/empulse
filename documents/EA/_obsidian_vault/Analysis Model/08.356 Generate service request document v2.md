# 🎯 08.356 Generate service request document v2

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/COMMON for Loan Services/Access Rights

## 📝 Notes

The version #2 with DMS integration of the current 08.356

A technical use case ensuring generation of a service request document. For generated document, The Document object is created and stored in the DMS component, the printout is created and stored into the File Storage (Cabinet) - ensured the DMS component.

Notice: If a Supplement is associated to the Service, this use case is not applied for service request documents generation, but the document setting is taken from the associated Supplement and documents are created under Contract Supplements Documents - see 13.205 Create contract supplement documents
