# 🎯 03.160 Get Installment Schedule

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/_Interface/Provided Web Services/Installment Schedule/Installment schedule/InstallmentScheduleRestAPIv1_new

## 📝 Notes

This technical, non-visual use case is used to find and return information about current installment schedule of selected contract. Returned data contains information about installments and their parts as well as information about payments paired to these installments.

Functionality works only with active installments - i.e. only information about current installment schedule is available, it's not possible to get information about historical installment schedules.

This functionality is used by external systems such as Collection system and provided through appropriate BSL interface.
