# 🎯 09.271 Import product to salesroom assignment file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Sales Network Management/Salesroom/Products on Salesroom/User Interface

## 📝 Notes

This visual use case is used to import file with instructions for assignment of products to salesrooms. User is able to select file with instructions from file system and after simple validations this file is registered for further processing by system. Processing is done asynchronously, so user needn't to wait until all instructions are processed.
