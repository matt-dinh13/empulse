# 🎯 01.171 Create REL contract termination request

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract finishing/Access Rights

## 📝 Notes

This use case allows create a contract termination request (only for contracts with REL account).

At first, the system gets data about account balance and contract termination (there is going about simulation to current date).
Obtained data are shown on a form, where the user have to specify an overpayment return method.
If the user submit the form, system sends a request for contract termination to the Card business system.    

At the same time the system creates a ContractStatusTransitionRequestForTermination according to the entered data on the form.
