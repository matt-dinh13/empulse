# 🎯 01.200 Add to contract package

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Contract package tracking/Access Rights

## 📝 Notes

This use case enables to insert into the system list of all documents relevant to currently processed contract  or supplement entered into package that is going to be sent to central office. If all necessary documents are checked and contract is correctly filled in, contract can be added to contract package.
