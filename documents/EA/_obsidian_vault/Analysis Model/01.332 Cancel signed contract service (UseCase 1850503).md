# 🎯 01.332 Cancel signed contract service

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract cancellation/Access Rights

## 📝 Notes

This use case presents a service which enables cancellation of the provided contract in SIGNED status (i.e. it process a request from ContractOperationsWS.CancelSignedContract)
In this case, if a incoming payment (from client) exists, the contract cannot be canceled.
In this case, if a paid outgoing payment exists, the contract is canceled in every way
