# 🎯 13.275 Show supplement registration

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/COMMON for Supplements/Contract Supplement operations/Contract Supplement registration/Access rights

## 📝 Notes

Purpose of this use case is to display supplement registration screen. The screen contains:

	
- Supplement documents required for registration


	
- List of recorded document mistakes under every document, with list of 'Set ticket state buttons' 


In this screen user may:

	
- Check presence of documents
	
- Record new document mistakes if it is needed
	
- Change state of recorded document mistakes 
	
- Register the Contract Supplement  if all critical mistakes are closed or canceled and presence of all required documents is checked
