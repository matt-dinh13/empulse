# 🎯 04.110 Process charging requests

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Installment Schedule/Fees and Penalties/Charging request/Access Rights

## 📝 Notes

This use case is invoked by 04.100 Add charging requests  (manual import) or by 04.123 Automatic add charging requests (automatic import) and describes how the charging requests are processed.
System performs a check for validity of each request structure. Within the validation, there are checked contract and tariff item existence.
If above mentioned validations pass, for each request is calculated tariff item amount and subsequently created particular installment - see 03.080 Add installment use case.
After all requests are processed, system notices user who run 04.100 Add charging requests or 04.123 Automatic add charging requests about result of file processing by the help of system internal message.
        
Actor:
It is run as included use case from following use cases:

	
- 04.100 Add charging requests
	
- 04.123 Automatic add charging requests
