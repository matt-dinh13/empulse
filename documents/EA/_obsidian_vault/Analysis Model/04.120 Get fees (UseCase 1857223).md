# 🎯 04.120 Get fees

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Installment Schedule/Fees and Penalties/Charging request/Access Rights

## 📝 Notes

This technical, non-visual use case is used to find and return information about fees and penalties which are part of selected contract. It's possible to restrict search for defined time interval. Also types of fees/penalties which are returned by this use case may be parameterized on the system level configuration.

This functionality is used by external systems such as Collection system and provided through appropriate BSL interface.
