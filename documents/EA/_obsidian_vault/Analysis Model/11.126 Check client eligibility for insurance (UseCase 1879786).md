# 🎯 11.126 Check client eligibility for insurance

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Insurance/Insurance Contract/Access Rights

## 📝 Notes

This use case describes checking client's eligibility criteria for insurance defined by Insurance Program. If the client is not eligible for the insurance, the Insurance Contract and related Contract Service are terminated. In this case, system sends notification message about this one.
