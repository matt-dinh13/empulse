# 🖥️ Error mesage

> **Type**: GUIElement · **Stereotype**: «text»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Contract package tracking/User Interface Model

## 📝 Notes

Error message row which explains the user errors which may occur when scanning barcodes. Message row is visible for user with access right 01.266 Check presence of contract with barcode reader. 

By default the error message is empty and invisible,when an error is detected in UC 01.266 Check presence of contract with barcode reader the message is displayed. The text of message is hidden after other user's action (clicking on some element, scanning of another barcode)
