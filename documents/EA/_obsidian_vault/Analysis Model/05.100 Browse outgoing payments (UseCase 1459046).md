# 🎯 05.100 Browse outgoing payments

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Outgoing payments/Browsing Outgoing Payments/Access Rights

## 📝 Notes

User executes this use case to browse outgoing payments in order to their next processing.
Searching possibilities of this functionality are presented in Browse outgoing payments screen.
User can selects unpaid payments to generate payment orders and run generating by 05.110 Generate payment orders use case.
For already processed payments (involved in a payment orders), there is possible to export a dispatch note file - see 05.125 Export dispatch note file use case.

Frequency of usage:
Several times a day
Actor:
User role authorized to run the UC
