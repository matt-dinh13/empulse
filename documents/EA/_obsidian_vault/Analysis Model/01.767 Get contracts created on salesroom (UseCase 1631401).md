# 🎯 01.767 Get contracts created on salesroom

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract API providing/Provide contract information/Access rights

## 📝 Notes

This use case presents a service for returning a list of contracts created on specified salesroom by specified user (optional) and specified contract status (optional) based on calling ContractWS.GetSalesroomContracts method.
This method does not provide data before contract signature, i.e. returned Contracts have to be in the following statuses: N, A, H, L, Q, K (Signed, Active, Paid off, Written off, Sold, Finished)
