# 📱 Application detail

> **Type**: Screen
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Application detail/User Interface Model

## 📝 Notes

Screen containing the detailed information about the particular loan application.

	
- Basic information about the application are displayed within the Application detail header panel - such panel is fixed in the upper part of the screen and is always shown no matter what tab is actually selected in the lower part of the screen.
	
- Within each individual tab in the lower part of the screen, a dedicated panel containing the information about the respective application properties or its related entities is displayed - for more details see the 01.210 Show contract detail use case.
