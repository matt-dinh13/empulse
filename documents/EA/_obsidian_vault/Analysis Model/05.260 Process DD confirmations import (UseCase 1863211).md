# 🎯 05.260 Process DD confirmations import

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Statements/Access Rights

## 📝 Notes

System calls this use case asynchronously to upload and process XML file containing direct debit statements confirmations received from bank and preprocessed outside of system. System parses file and updates DD statements status (debited/undebited) according to received information.

This use case can be invoked from 05.261 Automatic Import DD confirmations as well for automatic import
