# 🖥️ Add filter

> **Type**: GUIElement · **Stereotype**: «button»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Loan origination configuration /User Interface Model/Personal Document Container

## 📝 Notes

Pushing the button are displayed list of attributes, that can be filtered. Once the user selects any attribute, new field with the filter is added to the screen. Following attributes can be filtered:

	
- code - any string
	
- status- values NEW, ACTIVE, CANCELLED
	
- person role - value of enumeration Person Role
	
- person scoring segment- value of enumeration Person Scoring Segment
