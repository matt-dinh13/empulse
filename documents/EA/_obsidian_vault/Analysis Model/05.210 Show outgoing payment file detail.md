# 🎯 05.210 Show outgoing payment file detail

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Outgoing payments/Outgoing  payment files management/Access Rights

## 📝 Notes

User executes this use case to see detail of file containing outgoing payment orders. System displays information about file and list of contained payment orders.
User can perform following actions:

	
- export the file for next processing with 05.115 Export outgoing payment order file use case
	
- after choosing a payment order, export a dispatch note file for print with 05.125 Export dispatch note file use case 
	
- export the file for printing with 05.215 Print outgoing file for signing use case
