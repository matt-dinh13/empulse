> **Type**: GUIElement · **Stereotype**: «panel»

## 📝 Notes

Panel with operational buttons for application-related operations. 

Visibility of buttons:

	
- Visibility of individual functional buttons is controlled by the actual status of the respective application (see the preconditions of particular use cases associated to each button) no matter what tab is actually selected in the lower part of the Application detail screen - for more details see the 01.210 Show contract detail use case.
	
- Individual functional buttons are shown only if the user has assigned a privilege to run the associated use case (general rule).
	
- Individual functional buttons are shown only if all preconditions for the associated use case are fulfilled (different compared to general rules).
