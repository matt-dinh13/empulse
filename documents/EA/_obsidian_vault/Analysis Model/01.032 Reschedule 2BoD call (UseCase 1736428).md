# 🎯 01.032 Reschedule 2BoD call

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Support for 2BoD Processing/Access Rights

## 📝 Notes

This use case happens when user refuses filling application form and asks for a new time.
The user enters new date and time and confirms the action. The user can also change preferred mode of contacting the client.
The Search for contract screen is opened (user can continue with next contract or do other things) and is immediately refreshed.
