# 🖥️ Active snapshot

> **Type**: GUIElement · **Stereotype**: «form»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/Photo component/User Interface Model/Photo component (common panel)

## 📝 Notes

When photo component starts, then this frame is always empty. This place is intended for taken photos. In case of:
- PHOTO_CAPTURE_MODE = P only one photo is always displayed.
- PHOTO_CAPTURE_MODE = D more photos can be displayed. Each photo has possibility to delete it from the final result set by pushing Cross button. User can see enlarged image of the snapshot on mouse over

Localization code:
GEN_CurrentPhoto
