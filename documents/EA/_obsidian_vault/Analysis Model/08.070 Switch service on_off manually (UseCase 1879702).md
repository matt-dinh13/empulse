# 🎯 08.070 Switch service on/off manually

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/COMMON for Loan Services/Access Rights

## 📝 Notes

This use case describes the functionality of Service Operation Status - switching the service on or off.

Switching the service on means that the user will be able to actively use the service.

Example: 
The user wants to use the SMS Notification service. User asks for switching the service on. The service is switched on and the user starts receiving SMS messages. Once the user decides to stop receiving the SMS messages he asks for switching the service off.
