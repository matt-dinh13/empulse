# 🖥️ Taken photo/uploaded photo

> **Type**: GUIElement · **Stereotype**: «label»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/COMMON for Fill in application/User Interface Model/COMMON for User Interface/Document panel

## 📝 Notes

If document has taken/uploaded photo the file will be visible here. Depending on global parameter DownloadDocumentInAF, the user will be able to:
- download the file or
- view it in modal window
User will be also able to remove it.  (see UC 01.081, 01.082, 01.083 - part about documents for more details)

Displayed for document type that DOESN’T have flag 'PERSON' and 'PHOTO'
