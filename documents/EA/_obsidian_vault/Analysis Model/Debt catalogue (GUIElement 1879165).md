# 🖥️ Debt catalogue

> **Type**: GUIElement · **Stereotype**: «button»
> **Package**: HomerSelect/BSL/Analysis Model/Installment Schedule/Installment Schedule/User Interface Model

## 📝 Notes

Button is used to display information about current (or historical) debt catalogue of contract. It runs 01.473 Show debt catalogue detail use case

The button is accessible from the Payment channels tab and from the Installment schedule detail screen.

Button is unavailable in cases when doesn't exist any debt catalogue for displayed contract. This also applies to SAI contracts.

Localization code:
CON_DebtCatalogue
