# 🎯 01.265 Receive contract package

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Contract package tracking/Access Rights

## 📝 Notes

This use case enables to receive contract package at the central office and register information about presence of the contract and supplement documentation in the contract package. Registration status of received items is changed on RR (ready for registration). If some items are not received in package, they are removed from package and user who created package is informed about missing items with message to inbox.
