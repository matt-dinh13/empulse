# 🎯 01.580 Import DDM confirmation result

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Mandate (DDM)/DDM confirmation/Access Rights

## 📝 Notes

This use case enables to import direct debit mandates confirmation results. Import of DDM confirmation result is performed in following steps:

	
- DDM confirmation file is check if it is on compliant format
	
- Every DDM confirmation result is imported into system, where :
- System checks if DDM confirmation result is correct
- System checks if confirmation was not already imported or if DDM wasn't already canceled
- System imports confirmation result from import file
- For rejected DDM system changes contact payment channel on 'Other'
	
- In the end the user is notified that import of DDM confirmation results finished


This use case can be invoked from UC 01.570 Plan import of DDM confirmation results for manual import or from UC 01.585 Automatic import DDM confirmation result for automatic import.
