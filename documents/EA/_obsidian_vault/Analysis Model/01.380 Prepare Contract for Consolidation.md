# 🎯 01.380 Prepare Contract for Consolidation

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Loan consolidation/Access Rights

## 📝 Notes

The use case describes set of steps to prepare loan consolidation of chosen contracts.
The function is triggered by ContractConsolidationSE event. In this moment, consolidation contract (master contract which cover contracts are to be consolidated, it is a new contract) is signed, contracts for consolidation (client's current contracts which are within consolidation process finished) are chosen and outstanding debt on them is calculated and fixed (no change should happen).
System creates request for consolidation on the consolidation contract. Then suspends bonus services, cancel all active loan service requests and direct debiting on consolidated contracts.
Finally, a new FER request is created on consolidated contracts and in case the consolidation is determined only for refinancing (i.e. no extra cash payment for client). This step is done only for "internal" contracts (i.e. contracts originated by the HC company).
Notice: A full early repayment service definition for consolidated contract is taken form the consolidation service setting and set up on it, so FER is applied on the consolidated contract even if no FER service is assigned to that.
