# 🎯 03.035 Show early repayment preview

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Full Early Repayment/Access Rights

## 📝 Notes

- This functionality allows user to get information needed to the early repayment of loan in case a client asks for it.

The ER preview is done over one contract selected by the user.
During this action, following steps are performed:

	
- by the service setting, either a user can choose suitable date of ER or it is done automatically 
	
- calculation of all needed amounts to ER }

Next, it is checked if an ER request creating action is allowed. The check is performed on basis of the service setting. If the client's contract does not fulfill rules for ER, the ER request creating action is not allowed.
Finally, calculated ER amounts are displayed on the screen - see New Early repayment request and operator can inform the client about result.  

Frequency of usage:
A few requests a day created by back-office operators

Actor:
Authorized user
