# 🎯 04.100 Add charging requests

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Installment Schedule/Fees and Penalties/Charging request/Access Rights

## 📝 Notes

This UC is used to import charging requests. A charging request is a requirement to charge a fee or a penalty of defined type to particular contract. Input information contains only basic information such as contract number, fee/penalty identification or due date.
Amount of fee/penalty is not part of the charging request, because it is calculated from tariffs connected to contract.
User selects file through file selection dialog and system validate file for duplicity and format.
If the check passes, the file content is stored to the system to next processing - see 04.110 Process charging requests

Frequency of usage:
  The use case is run a few times a day on the back office only.
Actor:
  User authorized to creating charging requests
