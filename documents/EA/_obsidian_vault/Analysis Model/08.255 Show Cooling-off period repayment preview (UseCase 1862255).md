# 🎯 08.255 Show Cooling-off period repayment preview

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Cooling-off period/Access Rights

## 📝 Notes

This functionality allows user to get information needed to the early repayment of loan under cooling-off period in case a client asks for it.
The ER preview is done over one contract selected by the user.
During this action, following steps are performed:

	
- determination of suitable date of cooling-off ER
	
- calculation of all needed amounts for ER

Next, it is checked if creation of ER request under cooling-off period  is allowed.
Finally, calculated ER amounts are displayed on the screen and operator can inform the client about result.  

Frequency of usage:
A few requests a day created by back-office operators

Actor:
Authorized user
