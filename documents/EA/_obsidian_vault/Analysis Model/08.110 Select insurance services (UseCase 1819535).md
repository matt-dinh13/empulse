# 🎯 08.110 Select insurance services

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Insurance and Service Origination/Access Rights

## 📝 Notes

This use case describes selection of insurance services for loan application.

	
- system shows all insurance services available and sets current selection
	
- user has possibility to change selection by ticking/un-ticking checkboxes
	
- user can recalculate financial parameters of the offer
	
- system verifies all eligibility rules which can be evaluated according to known information and will not allow selection of ineligible insurance services.
