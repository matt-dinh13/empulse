# 🎯 11.772 Activate insurance on Contract event notification

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Insurance/Insurance Contract/Access Rights

## 📝 Notes

This use case describes activation of the insurance on contract events for REL contract type, i.e. establishing insurance period (i.e. start of insurance), checking insurance eligibility and sending specific notification.
Processed Contract system events:

	
- ContractSignSE
	
- ContractActivationSE


Insurance Service has to be set as follow only (Insurance type where premium is charged by AM) :

	
- First Period Trigger = CONTRACT_SIGNING_ DATE_AND_OFFSET/CONTRACT_ACTIVATION_DATE_AND_OFFSET
	
- First Period Duration = BILLING_PERIOD


For Insurance types charged by BSL, see Create insurance contracts for insurance services and UC 01.290 Activate contract
