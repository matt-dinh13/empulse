# 🎯 13.112 Refund Transaction Supplement

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Supplements/Transaction Supplement support/Access Rights

## 📝 Notes

The use case present functionality for refunding the already accepted Transaction Supplement.
Two variants of the refund are possible:

	
- full refund - the original transaction is cancelled in the AM, Transaction Supplement is changed into REFUNDED status
	
- partial refund - the original transaction is cancelled in the AM, a new transaction with decreased amount is created in the AM, Transaction Supplement status stays unchanged, TransactionSupplement


Example of the request: PUT <bsl_env>/bsl/api/v1.0/transaction-supplement/refund
