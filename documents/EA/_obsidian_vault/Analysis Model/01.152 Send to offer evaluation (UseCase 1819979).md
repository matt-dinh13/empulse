## 📝 Notes

This non-visual technical use case supports evaluation of the chosen offer. This use case is applicable only for accepted optional offers generated during the "main" approval process.
Since this action is asynchronous in the system, results from evaluation are obtained via UC 01.450 Receive evaluation result (particularly offer evaluation result).
