# 🖥️ Save and close

> **Type**: GUIElement · **Stereotype**: «button»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/Photo component/User Interface Model/Photo component

## 📝 Notes

When this button is used, then system takes currently active snapshot/snapshots and returns it to functionality which invoked photo component.

Button is active only when Currently active snapshot exists (i.e. it's not possible to save photo if photo doesn't exist).
