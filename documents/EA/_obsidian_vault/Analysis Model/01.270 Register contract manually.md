# 🎯 01.270 Register contract manually

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract registration/AccessRights

## 📝 Notes

Purpose of this use case is to enable registration of contract. 

User registers the contract by clicking on button 'Register contract' (button is enabled only if preconditions of this use case are met). 
After pressing the button, 

	
- System only calls REM module API for the Contract registration
	
- The retuned result is evaluated and system maps API result code to GUI message according to Map REM API Register result codes to GUI codes
