# 🎯 01.778 Cancel contract DDM service

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract API providing/Provide contract operation API/Contract DDM operations/Access Right

## 📝 Notes

This UC describes how to cancel a direct debit mandate on a contract. The functionality is exposed as web service to usage by an external system.
Cancellation of DDM is allowed: 

	
- for contracts in statuses (SIGNED, ACTIVE) if calling system role has basic privilege UC01_778


	
- for all contract statuses if calling system role has extended privilege UC01_778_AllStatuses (UC01_778 privilege is needed as well)
