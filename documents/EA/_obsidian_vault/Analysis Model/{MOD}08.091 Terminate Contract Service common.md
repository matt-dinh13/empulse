# 🎯 {MOD}08.091 Terminate Contract Service common

> **Type**: UseCase

## 📝 Notes

This use case describes procedure of service termination. Termination means finishing running service on contract at some date. User can terminate a service on a loan contract independently on the loan contract itself.
Notice: For Insurance termination, 11.121 Terminate insurance contract manually use case is used
