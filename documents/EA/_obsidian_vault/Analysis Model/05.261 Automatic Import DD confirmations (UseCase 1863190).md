# 🎯 05.261 Automatic Import DD confirmations

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Statements/Access Rights

## 📝 Notes

External system executes this use case to import file containing DD statements exported from DWH or DD statements confirmations received from bank. External system calls web service. System then creates asynchronous job and performs import of selected file.

Variant of Import DD files use case for import of DD confirmations.
