# 🖥️ Including recalculated transactions

> **Type**: GUIElement · **Stereotype**: «lcheckbox»
> **Package**: HomerSelect/BSL/Analysis Model/Account management/Account detail/User interface/Tab - Transaction History

## 📝 Notes

Checking the box means displaying also transactions which are canceled due to recalculation
The box is visible only if value ShowAccTransaction.ALL or ShowAccTransaction.CANCELLED_ONLY is set on Show transaction list.
The box is unchecked as default.

Localization code: ACC_IncludingRecalcTrans
