# 🎯 01.500 Pay-off contracts from file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract pay-off/Access Rights

## 📝 Notes

This technical, non-visual use case is used to bulk pay-off (terminate) contracts based on requests specified in file with defined structure. It processes file with requests for contract pay-off registered via UC 01.490 Plan pay-off of contracts from file. 
The functionality is limited only for CEL contracts.
