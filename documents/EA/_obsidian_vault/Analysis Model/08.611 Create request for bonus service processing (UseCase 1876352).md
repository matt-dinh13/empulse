# 🎯 08.611 Create request for bonus service processing

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Interest Back/Access Rights

## 📝 Notes

{ADD IS-2617} {PH only}
Use case describes creation of the request into the Bonus service request for process bonus service (periods creation, update, periods or evaluation).
Currently supports only Interest back service (IBACK).

Operation type of the requests depends on the triggering use case or system event:
-  GeneratedInstallmentScheduleSE: operation type: CREATE
- event IncomingPaymentPairingChangedCEL : operation type EVALUATE (note: this event is sending ISIR after IS recalculation, it could be triggered also after some other service evaluation together with operation type UPDATE or CANCEL)
- LoanServiceRequestExecutedSE: operation type UPDATE {DELDFPH-302}or CANCEL based on event type{/DEL}
- ContractInsuranceServiceCanceledSE: operation type UPDATE (processed by 08.292 Process Contract Service Change event)
- ContractInsuranceServiceTerminatedSE: operation type UPDATE (processed by 08.292 Process Contract Service Change event)
- ContractPaidOffSE: operation type CANCEL
- ContractCancelationSE: operation type CANCEL
- UC 08.210 Check and process Gift payment: : operation type CANCEL
- UC 08.220 Check and process Grace period: operation type CANCEL
- {ADD DFPH-302}ContractFinishingAutomaticallySE: operation type CANCEL{/ADD}
- {ADD DFPH-282} rule Renew IBACK periods: operation type UPDATE{/ADD}
