# 🎯 00.150 Find bank branch

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/COMMON for BSL/Bank Management/Bank management/Access Rights

## 📝 Notes

This use case is used to find any bank branch which is registered in Homer Select. User is able to use different attributes as search criteria. Usage of some attributes may be restricted by business and validation rules (e.g. minimal length of inserted value, inability to use some attribute as the only criteria etc.).
Functionality consists of search filter and list of found records. It's possible to do a follow up actions with found records.
