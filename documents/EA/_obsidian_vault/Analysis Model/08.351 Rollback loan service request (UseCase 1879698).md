# 🎯 08.351 Rollback loan service request

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/COMMON for Loan Services/User Interface

## 📝 Notes

The use case allows to perform a rollback of the already executed loan service request.
If rollback is successful, the Loan service request is canceled and LoanServiceRequestRollbackSE  is generated as part of rollback action called by API.

LoanServiceRequestRollbackSE is processed by 08.352 Process LoanServiceRequestRollbackSE event and itreates a Business Event and generate other system events (LoanServiceRequestCancelledSE , PaymentHolidaySE).

Currently only rollback of PAYHOL service is supported, but later it can be extended for other services.
