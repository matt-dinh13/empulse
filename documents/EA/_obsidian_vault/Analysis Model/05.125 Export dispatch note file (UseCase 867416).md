# 🎯 05.125 Export dispatch note file

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Outgoing payments/Dispatch notes/Access Rights

## 📝 Notes

User executes this use case to download dispatch note file printouts from the file system.
A printout for the dispatch note file is prepared and stored within the payment orders processing (see 05.120 Generate dispatch notes use case)
First, user has to choose a payment order for a dispatch note printing either via order file searching (see  05.190 Browse outgoing payment files and displaying the detail of the order file, or via outgoing payment searching (see  05.100 Browse outgoing payments use case )
If a dispatch notes printout is not prepared for any reason, system generates a new printout for the payment order.
