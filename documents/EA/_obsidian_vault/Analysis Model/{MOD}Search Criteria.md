# 🖥️ {MOD}Search Criteria

> **Type**: GUIElement · **Stereotype**: «panel»
> **Package**: HomerSelect/BSL/Analysis Model/Sales Network Management/Salesroom/Sales agents on Salesroom /User Interface/Assign Sales Agent

## 📝 Notes

At least one search criteria from Name/Employee number has to be filled.
For entering search criteria for these attributes, asterisk can be used in the end of entered search criteria (minimal length of word is 3 chars, example "Ste*"). That determines that the position of asterisk can be replaced by any string (except empty space). Search is performed in every word of full name received from UMC (USER.FULL_NAME). Word is every string that is separated from another string by empty space.
