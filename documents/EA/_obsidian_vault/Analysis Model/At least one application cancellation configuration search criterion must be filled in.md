# 📋 At least one application cancellation configuration search criterion must be filled in

> **Type**: Requirement · **Stereotype**: «validation»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Application cancellation configuration/Validation rules

## 📝 Notes

At least one of the following search criteria has to be filled in:

	
- Application status
	
- Application type
	
- Application creation channel
	
- Product profile code


Otherwise validation message MSG_AT_LEAST_N_FIELDS is shown.
