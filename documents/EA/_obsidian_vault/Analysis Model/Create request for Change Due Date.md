# 📱 Create request for Change Due Date

> **Type**: Screen
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Change of Due Date on request/User Interface

## 📝 Notes

System shows through this screen a set of change due date simulations (data from virtual installment schedules). 
The user can select one of provided simulations (i.e. he chooses an installment from which a change due date should be performed) and confirm the form.
The system then continues with a creation of new change due date request based on selected simulation.
