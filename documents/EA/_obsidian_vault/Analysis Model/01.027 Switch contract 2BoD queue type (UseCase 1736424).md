# 🎯 01.027 Switch contract 2BoD queue type

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Support for 2BoD Processing/Access Rights

## 📝 Notes

This use case describes how a contract/application can be handover from front office to back office and vice versa. The system displays a message that must be confirmed by the user. If the contract is passed to back office planned contact mode is set to PHONE.

Note: To prevent rescheduling the call to the start of working hour the next working day, it is recommended to reschedule call before switching the contract between front/back office.
