# 🎯 08.400 Show parameters for loan restructuring

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Loan Service Processing/Loan Option CEL/Loan Restructuring/Access Rights

## 📝 Notes

The use case shows basic data about a loan for the loan restructuring before creation of a request for that (CEL products only). Client asks for an amount which would like to pay each month and user enters this amount and creates a request for restructuring - see 08.402 Create request for loan restructuring use case. If an unfinished request exists for the processed contract and this request is approved, a screen with offers for restructuring is showed.
