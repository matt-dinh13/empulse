# 📋 01.650 Edit Contract Commodity

> **Type**: Requirement · **Stereotype**: «Access Right»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Contract commodities management/Access Rights

## 📝 Notes

Basic right for UC activation
Code=UC01_650
Rule Access control to Contract by Salesroom for contract detail is applied, user can access only to contracts originated logged on Salesroom or no restriction if Contract.Created remotely = true.

Salesroom where the contracts was originated is get according to the rule Get salesroom by operation, passed is Contract and operation = APPLICATION_CREATED.

If the user has also an access right 01.650 Edit commodity (all salesrooms), NO salesroom restriction is applied.

Rule Access control to Commodity by Contract status is applied, user can access selected contract statuses.
Rule Access control to edit commodity field is applied, user can access only selected fields.
