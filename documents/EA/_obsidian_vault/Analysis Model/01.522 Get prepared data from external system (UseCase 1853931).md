# 🎯 01.522 Get prepared data from external system

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/COMMON for BSL/Data prepared notification/Access rights

## 📝 Notes

This use case download data file from a directory of external system (File/Application server) and performs basic validations of that

The use is run at planned time - see Get prepared data from external storage job definition
UC can processes set of various requests:

	
- Credit limit change - it process data of a campaign with offers for credit limit change
	
- DDS requests


Frequency of usage and performance:

	
- It can run once a day (time after business hours is preferred; it also means the file has to be presented on defined place before this time so that could be processed the same day)
	
- One file a day can be processed
	
- Batch up to 200 000 records in one file
