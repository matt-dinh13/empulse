# 🎯 03.045 Generate IS printout

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Installment Schedule/Installment Schedule/Access Rights

## 📝 Notes

The use case describes generating an installment schedule printout at respective business event.
First, it is checked if a printout is to be generated for respective event (Product Profile Document setting is used here). If so, a printout data source is filled and and a printout (PDF format) is generated by using Print Server. To print is used template from Product version that was valid on Contract sign date.
Next, the generated printout is sent to the document storage (Cabinet).
Finally, the respective IS document is created, associated with the contract and the link to the document storage is stored to related DMS File object to later usage. 
Notice: this use case is not used to generate the first version of the installment schedule if it is done in the contract completion event (CIC). In this case, reference from an installment version to document is created in 01.180 Sign contract use case.
