# 🎯 01.010 Choose product offer

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Manage Product Offer/Access Rights

## 📝 Notes

This is a visual use case. Its purpose is to allow the user to find appropriate product and its financial parameters (product offer) according to client's needs. The use case has this basic steps:

	
- User enters search criteria like product type, financial preferences, documents, preferred services/insurance, eventually campaign offers, etc.
	
- System finds offers according to the criteria
	
- System displays the results
	
- User can choose a product offer and continue to application form (based on process type)


The calculation in short:

	
- System searches for candidates products by applying restrictions on product/salesroom type, validity, product limits, documents, commodity, etc.
	
- Based on the algorithm, which is set on the product, system tries to calculate an offer meeting client's preferences
	
- System calculates services/insurance
	
- System determines sales process for each calculated offer.


Additional information (terminology, algorithms) are in related entities (business rules).
