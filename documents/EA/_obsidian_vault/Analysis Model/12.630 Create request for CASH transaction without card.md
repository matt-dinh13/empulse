# 🎯 12.630 Create request for CASH transaction without card

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Account management/Cardless transactions support/User Interface Model

## 📝 Notes

The use case describes a system support for creation a Repeated Cash Disbursement (cardless) transaction (e.g. "loan on phone" request - LOP) on a request of client.
After a transaction amount entering, installment plan offers suitable for the loan are showed. Operator chooses one offer (based on client's preference) and confirm that. The transaction is sent to the Account management to authorization. The UC evaluates the returned response and inform the operator.
Notice: Confirmation of the transaction is performed by the Payment module.
{DEL CSI-2848}Keep in mind, a RELIP service (Installment Plan for REL transaction) has to exist on the contract to perform the action!{/DEL}
