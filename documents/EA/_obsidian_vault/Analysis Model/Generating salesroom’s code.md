# 📋 Generating salesroom’s code

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Analysis Model/Sales Network Management/Salesroom/COMMON for Salesroom/Business Rules/Common for all variants

## 📝 Notes

Salesroom‘s code is a numerical serie that is generated by the system. It is a 9 digit string that consists of:
- Partner code (first 5 digits) - code of the partner the salesroom belongs to
- Salesroom code (next 4 digits) - counter (from 0001 to 9999), new salesroom of the same partner uses the first free number in the array 
Example: Salesroom’s code 123456789 means that salesroom belongs to partner with partner’s code 12345 and it is the 6789th salesroom of this partner. To find a salesroom using a salesroom code, whole (9 digit) salesroom‘s code has to be entered as a search criteria.
