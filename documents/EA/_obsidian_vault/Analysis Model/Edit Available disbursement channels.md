## 📝 Notes

Available disbursement channels for Partner/Salesroom.

Saving:
If any disbursement channel is newly selected, then record in appropriate entity (PartnerDisbursementChannel, SalesroomDisbursementChannel) will be created with Archived = "false".
If any already selected disbursement channel is deselected, then appropriate record will be set to Archived = "true".
