# 🎯 01.759 Get contract services for self-care

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Customer Self-Care API/Access Rights

## 📝 Notes

Use case provides list of contract services for self-care purposes

Response is limited only to currently valid contract services.

...openapi/v5.0/customers/{customerId}/contracts/{contractNumber}/services
e.g.: https://bsl.in00c1.in.infra/bsl/openapi/v5.0/customers/10132756/contracts/4000000028/services

...openapi/v5.0/customers/{customerId}/contracts/{contractNumber}/services/{serviceId}
e.g.: https://bsl.in00c1.in.infra/bsl/openapi/v5.0/customers/10132756/contracts/4000000028/services/1234567
