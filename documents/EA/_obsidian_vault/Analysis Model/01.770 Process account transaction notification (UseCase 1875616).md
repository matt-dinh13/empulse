# 🎯 01.770 Process account transaction notification

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Account management/Credit account notification processing/Access rights

## 📝 Notes

This use case describes how notifications about the first (initial) transactions generated by Cabus AM or ContractSignTransactionsSE event are processed in Insurance. In short, the following steps are performed:

	
- set start of the insurance(s) assigned to the contract
	
- activate insurance contracts
	
- create insurance outgoing payments
	
- confirm insurance transactions
