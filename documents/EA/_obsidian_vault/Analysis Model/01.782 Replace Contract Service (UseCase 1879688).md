# 🎯 01.782 Replace Contract Service

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/Customer Self-Care API/Access Rights

## 📝 Notes

The use case describes replacing of the current Contract Service by new Contract service on an external request.
Contract for which a Contract Service will be replaced has to be in one of allowed statuses.

Create request example: POST <BSL_ADDRESS>/openapi/v1.0/contractservices/{serviceId}/replace
{
  "serviceCode": "somecode",
  "serviceVersion": "6",
  "replaceReason": "test",
  "switchOn": "0",
  "skipAM:" "1"
}
