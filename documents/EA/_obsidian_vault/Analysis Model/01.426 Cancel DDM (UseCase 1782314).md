# 🎯 01.426 Cancel DDM

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Payments/Direct Debit Mandate (DDM)/Create/Update/Receive DDM/Access rights

## 📝 Notes

Purpose of this use case is to cancel existing Direct Debit Mandate (DDM). This is a visual use case.

User cancels the specific DDM in DDM tab of Contract detail. Cancellation is allowed:

	
- only to user who may access this usecase
	
- for contracts in statuses (SIGNED, ACTIVE)


	
- and for DDMs in statuses (NEW, AVAILABLE, SENT_FOR_CONFIRMATION, RECEIVED_FROM_CONFIRMATION with DDM.CONFIRMATION_STATUS = APPROVED)



	
- To cancel DDM the user has to press 'Cancel DD Mandate' button.
	
- Then in opened modal window the user must select cancellation reason from combo-box and confirm cancellation with pressing the button 'OK'.
	
- After that the mandate is canceled (DDM status is set to Canceled (CNC)) and cancellation reason is saved to DDM attribute CONFIRMATION STATUS REMARK
	
- Payment channel of contract is set to 'Other'
	
- After cancellation,  'Cancel DDM' window is closed and the DDM tab is refreshed.
