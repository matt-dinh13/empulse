# 📋 Preferred language choice restriction

> **Type**: Requirement · **Stereotype**: «Functional»
> **Package**: HomerSelect/BSL/Analysis Model/Contract Origination/Fill in application/COMMON for Fill in application/Business Rules/Product

## 📝 Notes

User can select two preferred languages in Preferred language and Second preferred language. When language is selected in one of the comboboxes, then it cannot be visible in the other combobox. 
Example: List of languages - English, Hindi, Urdu
User selects English in Preferred language. In Second preferred language system shows only Hindi and Urdu.
Same will happen if user selects English in Second preferred language, i.e. Preferred language will show only Hindi and Urdu.
