# 🎯 01.864 Generate notifications about contract securitization

> **Type**: UseCase
> **Package**: HomerSelect/BSL/Analysis Model/Contract Management/COMMON for Contract Management/Messages processing/Business Rules

## 📝 Notes

This technical use case describes processing of the SecuritizationTrancheProcessedSE system event which is triggered after a contract securitization tranche is successfully processed. Within the UC steps, ContractSecuritizedSE system event for each contract contained in the securitization tranche (needed for generation ContractFullInfo notification) and ContractSecuritizationNotification message with data for booking are generated.
