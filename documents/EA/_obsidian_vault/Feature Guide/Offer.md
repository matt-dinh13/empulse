# 📁 Offer

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Feature Guide/LOR

## 📝 Notes

Offers are created using user interface of product calculator or automatically as alternative offers based on evaluation process. Selected offer is afterwards linked to particular application. 

## Data structure
- Offer financial parameters
- Offer service
- Offer insurance service and custom data
- Offer tariff
- Offer subvention

## Detail
User can display detail of each offer that is generated. This detail includes mainly information about:

- product description
- financial parameters
- interest rates
- fees and services
- required client documents

Moreover it allows user to:

- select insurance
- adjust credit limit
- change offer parameters (e.g. preferred due day or installment schedule method)
- print detail of the offer or display preliminary installment schedule
