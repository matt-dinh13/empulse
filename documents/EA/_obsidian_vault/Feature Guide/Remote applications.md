# 📁 Remote applications

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Feature Guide/LOR

## 📝 Notes

Application can be created by telesales operator/e-shop and finished in any point of sales.

## Output

## Detail
There is a possibility to create 1st block of data (BoD) using telesales operator or any e-shop/mobile application. Such application is marked as "remote".
Depending on the current process, finalizing the application form (2nd BoD) and/or signed on any regular point of sales (POS). Applicant then has to come to required POS and sales agent has to search remote application using initial client search or standard contract search.

_Note: Sales agent is not able to see other applicant's standard contracts created on other regular salesrooms._
