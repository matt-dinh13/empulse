# 📁 Supplements

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Feature Guide/CLM

## 📝 Notes

Section of **Contract detail**, which is used to show list of supplements and their details - entities used for processing **Credit limit change** operation or processing of any **Collection tool services** (see Services). When the request for the operation above is created, the supplement entity is created as well.

In this section of UI it's possible to manually create request for **Credit limit change - decrease**. As the name suggests user is able to decrease the credit limit of revolving loan contract on demand. The opposite operation **Credit limit increase** is currently done only through importing XML file.
