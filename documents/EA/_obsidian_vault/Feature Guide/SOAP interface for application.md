# 📁 SOAP interface for application

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Feature Guide/LOR

## 📝 Notes

The aim of interface is to enable the customers to create contracts through any other system, e.g. by providing the option to apply for a loan using e-shops. Communication with surrounding systems is realized via SOAP API. Any surrounding system with appropriate access rights can call any our method and receive message as response to their call. List of available methods is described in Service Catalog and supports whole process of loan origination from creating to signing the application.
