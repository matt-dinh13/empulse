# 📁 Contract Securitization

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Feature Guide/CLM

## 📝 Notes

- changing contract's ownership for securitization purposes.

The securitization process starts by importing xml file containing contract codes, owner code, sale date and optionally sale price, sale fee.

During process the contract changes it's ownership and certain values are calculated from installment schedule parameters - installments, principals, fees mainly between sale date and last due date before sale date.
