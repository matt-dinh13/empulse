# 📁 Document containers

> **Type**: Package · **Stereotype**: «feature»
> **Package**: HomerSelect/BSL/Feature Guide/LOR

## 📝 Notes

Document containers defines documents that needs to be presented by application and added to the application in order to process it further.

## Data structure
- Document type
- Document container
- Document type to document container

## Detail
In order to submit application for loan, application must fulfill all conditions defined by assigned containers to the product that includes:

- allowed document types
- number of required documents
- if (mandatory/option/forbidden) and how (scan/take photo) photo of document should be provided
